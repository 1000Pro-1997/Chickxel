내 컴퓨터에 맞는 파일을 누르면 다운로드가 시작됩니다. Mac 칩은 Apple 메뉴 → 이 Mac에 관하여에서 확인합니다.

Windows macOS · Apple Silicon macOS · Intel

다 받은 뒤에는 아래 안내대로 처음 실행하고, 사용 가이드에서 첫 사용 흐름을 따라가 보세요.

Windows

처음 실행할 때 파란 경고 창이 뜨면

Chickxel은 개인 개발자가 만든 앱이라 아직 코드 서명(Microsoft가 인정하는 게시자 인증서)이 없습니다. 그래서 Windows가 처음 보는 앱을 한 번 막습니다. 파일에 문제가 있다는 뜻은 아닙니다.

받은 Chickxel-windows-x64.zip을 우클릭해 모두 압축 풀기를 누르고, 풀린 폴더의 Chickxel.exe를 더블클릭합니다.

Windows의 PC 보호 창이 뜨면 ① 추가 정보를 누릅니다. 실행 안 함을 누르면 창만 닫히고 Chickxel은 실행되지 않습니다.

② 게시자가 알 수 없는 게시자로 나오는 것은 코드 서명이 없어서입니다. ③ 실행을 누르면 Chickxel이 열리고, 다음부터는 이 창이 뜨지 않습니다.

창이 아예 뜨지 않게 하려면: 압축을 풀기 전에 zip을 우클릭 → 속성을 누르고, 아래쪽 차단 해제에 체크해 확인을 누른 뒤 압축을 풉니다.

Edge에서 다운로드가 멈추면: 다운로드 목록에 "일반적으로 다운로드되지 않습니다"가 뜨면 그 줄의 기타 옵션(점 세 개) → 유지 → 더 보기 → 그래도 계속을 누릅니다.

실행 단추 없이 막히면: 스마트 앱 컨트롤이 켜진 PC는 서명 없는 앱을 실행하지 못하게 합니다. 이 기능을 끄는 것은 권하지 않으니 Discord나 문제 신고로 알려 주세요.

경고 없이 설치하기 (PowerShell)

시작 메뉴에서 PowerShell을 열고 아래 한 줄을 붙여 넣은 뒤 Enter를 누릅니다. GitHub에서 최신 버전을 받아 %LOCALAPPDATA%\Programs\Chickxel에 설치하고, 시작 메뉴에 바로 가기를 만든 뒤 실행합니다. 브라우저로 받은 파일이 아니라서 Windows의 PC 보호 창이 뜨지 않습니다.

irm https://raw.githubusercontent.com/1000Pro-1997/Chickxel/main/install.ps1 | iex
macOS

처음 열 때 "확인되지 않은 개발자" 경고가 뜨면

Apple 개발자 서명이 없어서 처음 한 번 경고가 뜹니다. 파일에 문제가 있다는 뜻은 아닙니다.

  1. 받은 zip을 더블클릭해 풀고, Chickxel.app을 응용 프로그램 폴더로 옮깁니다.
  2. Chickxel.app을 우클릭해 열기를 누르고, 묻는 창에서 한 번 더 열기를 누릅니다.
  3. 그래도 열리지 않으면 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 그래도 열기를 누릅니다.

경고 없이 설치하기 (터미널)

터미널 앱에 아래 한 줄을 붙여 넣은 뒤 Enter를 누릅니다. Mac 칩에 맞는 최신 버전을 GitHub에서 받아 /Applications/Chickxel.app에 설치하고 실행합니다.

curl -fsSL https://raw.githubusercontent.com/1000Pro-1997/Chickxel/main/install.sh | sh

받은 파일이 원본인지 확인하려면

Chickxel은 GitHub 릴리스와 이 홈페이지에서만 배포합니다. 받은 zip의 SHA-256 값(Windows PowerShell Get-FileHash 파일.zip, macOS 터미널 shasum -a 256 파일.zip)이 릴리스에 함께 올린 SHA256SUMS.txt의 값과 같으면 원본 그대로입니다.

설치가 안 되거나 Windows 보안이 파일을 격리했다면 알림에 나온 이름과 함께 Discord로 알려 주세요.
