# Gpixel

[![ci](https://github.com/1000Pro-1997/GPixel/actions/workflows/ci.yml/badge.svg)](https://github.com/1000Pro-1997/GPixel/actions/workflows/ci.yml)
[![release](https://img.shields.io/github/v/release/1000Pro-1997/GPixel)](https://github.com/1000Pro-1997/GPixel/releases/latest)
[![license](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

게임(특히 Unity 2D)용 픽셀 아트 편집기입니다(Windows·macOS). 프레임·레이어·태그(애니메이션)는 `.gpixel` 프로젝트에 저장되고, 저장할 때 **PNG 스프라이트 시트 + Unity `.meta`**가 함께 내보내집니다.

## 설치·실행 (그냥 쓰기 — .NET 설치 필요 없음)

### 바로 받기

| OS | 내려받기 (최신 버전) | 실행 |
|---|---|---|
| Windows 10/11 (x64·ARM64) | [Gpixel-windows-x64.zip](https://github.com/1000Pro-1997/GPixel/releases/latest/download/Gpixel-windows-x64.zip) | 압축을 풀고 `Gpixel.exe` 더블클릭 |
| macOS 12+ Apple Silicon (M1 이후) | [Gpixel-macos-arm64.zip](https://github.com/1000Pro-1997/GPixel/releases/latest/download/Gpixel-macos-arm64.zip) | 압축을 풀고 `Gpixel.app`을 응용 프로그램 폴더로 옮긴 뒤 더블클릭 |
| macOS 12+ Intel | [Gpixel-macos-x64.zip](https://github.com/1000Pro-1997/GPixel/releases/latest/download/Gpixel-macos-x64.zip) | 위와 같음 |

지난 버전과 바뀐 점은 [Releases](https://github.com/1000Pro-1997/GPixel/releases)에 있습니다. 내 Mac 칩은  메뉴 → 이 Mac에 관하여에서 확인합니다.

### 터미널로 설치

**macOS** (터미널 앱에 붙여 넣기 — 칩에 맞는 파일을 골라 `/Applications/Gpixel.app`에 설치하고 실행):

```sh
ARCH=$(uname -m); [ "$ARCH" = x86_64 ] && ARCH=x64
curl -fL -o /tmp/Gpixel.zip "https://github.com/1000Pro-1997/GPixel/releases/latest/download/Gpixel-macos-$ARCH.zip" \
  && rm -rf /Applications/Gpixel.app && ditto -x -k /tmp/Gpixel.zip /Applications \
  && xattr -dr com.apple.quarantine /Applications/Gpixel.app; rm -f /tmp/Gpixel.zip; open /Applications/Gpixel.app
```

**Windows** (PowerShell에 붙여 넣기 — `%LOCALAPPDATA%\Programs\Gpixel`에 설치하고 시작 메뉴에 바로 가기를 만든 뒤 실행):

```powershell
$d = "$env:LOCALAPPDATA\Programs\Gpixel"; $z = "$env:TEMP\Gpixel.zip"; $x = "$env:TEMP\Gpixel-x"
Invoke-WebRequest "https://github.com/1000Pro-1997/GPixel/releases/latest/download/Gpixel-windows-x64.zip" -OutFile $z
Expand-Archive $z $x -Force; New-Item -ItemType Directory -Force $d | Out-Null
Copy-Item "$x\Gpixel-windows-x64\Gpixel.exe" $d -Force; Unblock-File "$d\Gpixel.exe"; Remove-Item $z, $x -Recurse -Force
$s = (New-Object -ComObject WScript.Shell).CreateShortcut("$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Gpixel.lnk"); $s.TargetPath = "$d\Gpixel.exe"; $s.Save()
Start-Process "$d\Gpixel.exe"
```

두 방법 모두 내 계정이 쓸 수 있는 곳에 설치하므로, 이후 업데이트는 앱 안에서 자동으로 됩니다(아래 "업데이트").

### 처음 실행할 때

- 개발자 서명이 없는 앱이라 처음 한 번은 경고가 뜹니다.
  - Windows "PC 보호" 창: **추가 정보 → 실행**.
  - macOS "확인되지 않은 개발자": `Gpixel.app` **우클릭 → 열기**. 안 되면 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**, 또는 터미널에서 `xattr -dr com.apple.quarantine /Applications/Gpixel.app`.
- macOS: 단축키의 Ctrl은 ⌘(Command)입니다(예: ⌘S 저장, ⌘⇧O 폴더 열기). 메뉴와 도움말에도 ⌘로 표시됩니다. 스포이드는 ⌥+클릭, ⌘를 누르는 동안은 임시 이동 도구.
- 명령줄: Windows `Gpixel.exe --open-folder <폴더> --open <파일.gpixel|파일.png>`, macOS `open -a Gpixel --args --open <파일>` (경로만 주면 `--open`).

### 업데이트

Gpixel은 시작할 때마다 GitHub 릴리스에서 새 버전을 확인합니다(배포판만, 개발 빌드는 확인하지 않음). 새 버전이 있으면 **업데이트 창**이 뜨고 위 막대에 **업데이트** 단추도 나타납니다. 창의 **다음 업데이트까지 띄우지 않기**를 고르면 그 버전은 다시 띄우지 않고 더 새 버전이 나올 때 알리며, **나중에**는 다음 실행 때 다시 알립니다. **도움말 > 업데이트 확인…**으로 언제든 직접 확인할 수 있고, **편집 > 환경 설정… > 일반**에서 자동 확인을 끌 수 있습니다. 확인은 GitHub 웹의 최신 릴리스 주소로 해서 GitHub API의 시간당 60회 한도에 걸리지 않습니다.

업데이트 창에는 지금 버전 다음부터 새 버전까지의 **바뀐 점**이 보입니다(저장소의 [CHANGELOG.md](CHANGELOG.md)를 릴리스와 함께 올려 읽음). 못 읽으면 그 버전의 릴리스 페이지 주소를 보여 주고, 창 아래 **"Gpixel X.Y.Z 바뀐 점 — 릴리스 페이지 열기"** 링크(바깥 링크 아이콘)는 늘 있습니다.

업데이트 창에서 **지금 업데이트**를 누르면 이 OS·CPU용 zip을 내려받아 릴리스의 `SHA256SUMS.txt`로 검증한 뒤, 앱을 닫고 새 버전으로 바꿔 다시 실행합니다(저장하지 않은 작업은 먼저 묻고, 실패하면 이전 버전을 그대로 둡니다). 설치 폴더에 쓸 권한이 없거나(예: 권한 없는 /Applications) Linux에서는 릴리스 페이지에서 직접 받으세요.

### 네트워크·개인정보

Gpixel은 계정·분석·광고 기능이 없고, 그림이나 파일을 어디로도 보내지 않습니다. 네트워크는 다음 경우에만 씁니다.

- **업데이트 확인**: `github.com`의 최신 릴리스 주소와(새 버전일 때 바뀐 점을 읽으려고) `api.github.com`에 묻습니다(앱 버전이 든 User-Agent만 보냄). 끌 수 있습니다.
- **팔레트 웹(Lospec)**: 그 창을 열었을 때만 `lospec.com`에서 팔레트 목록·예시 그림을 받습니다.
- **AI 채팅(Claude·Codex)**: 그 창을 쓸 때만, 컴퓨터에 설치된 Claude Code CLI 또는 Codex CLI가 사용자 자신의 로그인으로 Anthropic·OpenAI에 접속합니다. Gpixel 쪽 도구 서버는 `127.0.0.1`에서만, 무작위 토큰으로 열립니다.

## 배포 파일 만들기

- macOS: `./publish.sh 1.0.0` → `dist/`에 Windows zip + macOS(arm64·x64) zip 세 개(Mac 한 대에서 둘 다 만듦).
- Windows: `publish.bat 1.0.0` → `dist\Gpixel-windows-x64.zip`(Windows용만).
- GitHub: `git tag v1.0.0 && git push origin v1.0.0` 하면 Actions(`.github/workflows/release.yml`)가 테스트 후 세 zip과 `SHA256SUMS.txt`를 만들어 릴리스에 올립니다. 자동 업데이트가 이 파일 이름(`Gpixel-windows-x64.zip`, `Gpixel-macos-arm64.zip`, `Gpixel-macos-x64.zip`, `SHA256SUMS.txt`)과 `vX.Y.Z` 태그를 기대하므로 바꾸지 마세요.
- 새 버전을 올리기 전에 [CHANGELOG.md](CHANGELOG.md) 맨 위에 `## vX.Y.Z (날짜)` 절을 쓰면, 그 절이 릴리스 설명이 되고 앱 업데이트 창에도 나옵니다(절이 없으면 GitHub 자동 노트).
- 푸시·풀 리퀘스트마다 `.github/workflows/ci.yml`이 Windows·macOS·Linux에서 빌드하고 테스트합니다.
- 결과물은 .NET 런타임을 품은 자체 포함 앱이라 받는 사람이 아무것도 설치하지 않아도 됩니다(zip 40MB 안팎).

## 개발

- 필요: .NET 10 SDK. UI는 Avalonia(Windows·macOS·Linux 공용 코드).
- 소스에서 바로 실행: Windows `run.bat` · macOS/Linux `./run.sh` (인수는 그대로 앱에 넘어감)
- 빌드·테스트: `dotnet build Gpixel.sln`, `dotnet test Gpixel.sln`
- 작업 규칙: [AGENTS.md](AGENTS.md) — UI에 이모지·기호 문자를 아이콘으로 쓰지 않고 벡터(SVG 경로) 아이콘으로 그립니다(`VectorIcons.cs`). 문서·커밋 메시지에도 이모지를 쓰지 않습니다.
- 아이콘: 도구 아이콘은 `src/Gpixel.App/Assets/Tools/*.png`(16×16 단색 점 그림, 도구 막대에는 2배로 표시), 앱 아이콘은 `Assets/AppIcon/`(16×16 원본 `gpixel.png`에서 만든 `gpixel.ico`·`Gpixel.icns`·창/Dock 아이콘 `gpixel-256.png`). PNG는 Gpixel로 열어 바로 고칠 수 있습니다.

## 화면 (Aseprite식 배치)

- **메뉴** 아래 막대: 현재 도구 이름과 사용법 한 줄, 오른쪽에 보기 옵션(격자, 타일 격자, 타일 모드, 피벗, 양파 — 단추를 **우클릭**하면 그 보기의 설정 팝업이 뜨고 바꾸면 바로 적용, 꺼져 있으면 켬: **격자** = 색(알파 = 진하기)·보이기 시작하는 배율(2~16배, 기본 6배), **타일 격자** = 타일 가로·세로(8·16·32·64 바로 고르기)·색, **타일 모드** = 반복 크기(자동·3×3·5×5·7×7)·가운데 둘레 어둡게, **양파** = 앞·뒤 프레임 수(0~5)·진하기(멀수록 옅게)·색 물들이기(앞 빨강, 뒤 파랑))·확대율 숫자 상자(클릭 = 직접 입력, 좌우로 끌기 = 한 배씩, 우클릭 = 화면에 맞추기·100%~6400% 목록)·**맞추기** 토글(켜면 이미지를 열 때마다 화면에 맞춤, 켜는 순간에도 한 번 맞춤; Ctrl+0은 언제든 지금 맞추기)·AI 채팅 단추. 도구의 세부 설정은 오른쪽 독 **도구 설정**에 있습니다. 숫자·글자 입력란을 고친 뒤 다른 곳(캔버스 등)을 누르면 입력 상태가 끝나고 값이 확정됩니다. **모든 숫자 상자**는 입력 중이 아닐 때 **우클릭**하면 예시 값 목록이 떠서 바로 고를 수 있습니다(지금 값은 점 표시, 상자에 따라 맨 위에 "화면에 맞추기" 같은 특수 항목, 크기·FPS 등은 자주 쓰는 값, 그 밖에는 범위에 맞춰 자동).
- **왼쪽 끝 세로 도구 막대**(점 그림 아이콘, 도움말에 단축키) — 맨 위 폴더 단추로 파일 브라우저를 접고 펼침(F8). 비슷한 도구는 한 칸에 묶이고(오른쪽 아래 삼각형), 길게 누르거나 오른쪽 클릭하면 옆에 펼쳐 바꿉니다([도구](#도구)). 맨 아래에는 **저장**(Ctrl+S와 같음)·**저장한 내용으로 되돌리기** 단추가 붙어 있습니다(창이 낮으면 도구 칸만 스크롤). 저장 안 한 수정이 있을 때만 켜지고(꺼지면 흐리게), 되돌리기는 디스크에 파일이 없으면(저장한 적 없는 새 프로젝트) 꺼져 있습니다([파일](#파일)).
- **파일 브라우저**: F8·폴더 단추로 열고 닫을 때 폭이 부드럽게 늘고 줄며, 제목 줄 오른쪽 끝 아이콘 셋(VS Code처럼) — **새 픽셀 파일**(새 프로젝트 창이 뜨고 확인하면 트리에서 고른 폴더에 `.gpixel`로 만들어 엶) · **새 폴더**(이름을 물어 고른 폴더 안에 만들고 그 폴더를 고름) · **새로 고침**(누르면 한 바퀴 돌며 새로 고침; 폴더·Unity 프로젝트 열기는 파일 메뉴 Ctrl+Shift+O / Ctrl+Shift+U), 폴더 트리, `.gpixel`·PNG 썸네일 목록(`.gpixel` 프로젝트는 썸네일 오른쪽 아래 파란 레이어 배지로 표시, 프로젝트가 내보내는 이미지 — 같은 이름 PNG와 등록된 프레임 시트·부위 아틀라스 — 는 목록에서 빼고 `.gpixel` 하나로 보여 주며, 마우스를 올리면 내보내는 파일 이름이 보이고 그 이름으로 검색해도 찾음), 검색, 하위 폴더 포함, 파일 변경 감시, 우클릭(새 프로젝트·합치기·이름 바꾸기·탐색기/Finder에서 보기·삭제·`.gpixel` 파일만 삭제·마지막 삭제 되살리기·앱 휴지통 보기). Unity Hub 프로젝트 목록(Windows `%APPDATA%\UnityHub`, macOS `~/Library/Application Support/UnityHub`; 최신 Hub의 `hub.db`를 먼저, 없으면 `projects-v1.json`)에서 바로 열기.
  - **여러 개 고르기**: Ctrl/⌘+클릭(하나씩 더하고 빼기), Shift+클릭(범위), 또는 목록 위를 **끌어서 사각형**으로(Ctrl/⌘를 누르고 끌면 지금 선택에 더함, 위·아래 밖으로 끌면 스크롤). 그냥 클릭으로 하나만 고르면 엽니다(여럿을 고를 때는 열지 않음).
  - **저장하지 않은 변경(빨간 점)**: 다른 파일을 열어도(파일 목록 클릭·최근 파일·열기·새 프로젝트·닫기) 저장 여부를 묻지 않습니다. 고친 파일은 메모리에 그대로 남고(수정 내용·실행취소 기록·현재 레이어/프레임·확대율·위치), 파일 목록에서 그 칸 썸네일 **왼쪽 위에 빨간 점**(마우스를 올리면 "저장하지 않은 변경 있음")이 붙으며 썸네일도 메모리 속 그림으로 보입니다. 지금 열린 파일도 고치면 바로 점이 붙고 저장하면 사라집니다. 다시 누르면 디스크가 아니라 메모리의 그 문서를 이어서 편집합니다(Ctrl/⌘+Z로 그 전 편집도 되돌림). 상태 표시줄에 "저장 안 한 파일 N개"가 보입니다. 점이 붙은 파일의 이름을 바꾸면 따라가고, 휴지통으로 보내면 메모리의 변경은 버립니다(디스크 내용은 앱 휴지통에). 밖에서 그 파일이 바뀌어도 메모리 쪽은 그대로 두고 알리기만 합니다(저장하면 덮어씀). 아직 저장 위치가 없는 새 프로젝트만 다른 파일로 바꿀 때 저장 여부를 묻습니다. AI 도구(open_file·new_project)도 같은 규칙이라 파일이 있는 문서는 메모리에 남기고 바꾸며, 저장한 적 없는 새 프로젝트에 수정이 있을 때만 실패합니다.
  - **합치기…**(2개 이상 고르고 우클릭): 창에서 순서(줄을 **끌어서** 바꿈 — 끄는 줄이 떠서 따라오고 다른 줄이 비켜 서며 놓으면 미리보기 갱신, 위/아래 단추도 됨, 위 = 먼저), 이름(모든 파일 이름에 공통인 앞·뒤 단어 — 예: `potato_growing`·`potato_mature` → `potato`, 없으면 처음 고른 파일 이름, 고칠 수 있음), 방식 — **레이어로**(파일마다 레이어, 첫 파일이 맨 위) / **그룹으로**(그룹 하나에 파일마다 부위, 파일 크기 그대로) / **스킨으로**(`.gpixel` 그룹이 없으면 그룹 하나에 부위 "부위" 하나, 파일마다 그 그룹의 스킨 — 스킨 이름 = 파일 이름, 첫 파일 = 첫(기본)·지금 스킨, 부위 크기 = 가장 큰 파일이고 작은 파일은 부위 안 기준점에, 프레임이 모자란 스킨은 첫 스킨을 물려받음 — 같은 자리에 바꿔 끼우는 타일·아이템 변형용) / **프레임으로**(파일 순서대로 프레임을 이어 붙임, 프레임 하나짜리 파일은 칸 이름 = 파일 이름, 여러 프레임 파일은 자기 태그나 파일 이름 태그) — **그룹으로** 줄 오른쪽의 **빈 대표 이미지**(그룹으로를 고를 때만 켤 수 있고 아니면 회색)를 켜면 그 그룹의 부위를 모두(`.gpixel` 그룹에 더할 때는 원래 부위도) 숨긴 채로 만들어 그룹 행(대표 이미지)과 프레임 시트가 비어 보입니다(부위 그림은 그대로라 부위 아틀라스에는 모두 나가고, 타임라인에서 눈을 켜면 보임) — 캔버스 크기(기본 = 가장 큰 파일, "가장 큰 크기"), 기준점(9방향), **원본 삭제**(앱 휴지통으로)를 정하고 미리보기(여러 프레임이면 재생)를 보며 합칩니다. 창 아래 **"타임라인에서는 이렇게 보입니다"**에 결과의 타임라인 모양(행 = 레이어·그룹(펼친 삼각형)·부위(가지 선)와 크기·스킨(빈 마름모)·부위 전용 스킨(채운 마름모)(스킨이 여럿인 부위 아래 흐린 행, 실제 타임라인은 지금 스킨만), 열 = 프레임 번호·길이, 칸마다 썸네일, 태그 띠)이 나오고 방식을 바꾸면 바로 바뀝니다. **`.gpixel`의 구조는 어느 방식이든 버리지 않고 그대로 옮깁니다**(레이어·그룹·부위 크기/위치/피벗/테두리·스킨·부위 전용 스킨·지금 스킨·효과·자동 배치·태그·프레임 길이/칸 이름/피벗, 착장은 복사한 그룹·스킨을 가리키게) — **레이어로**는 레이어·그룹을 통째로, **그룹으로**는 그룹이 있는 첫 `.gpixel`의 맨 위 그룹에 그림 파일을 새 부위로 더하고(목록에서 그 파일보다 앞 파일은 원래 부위 위, 뒤 파일은 아래; 그룹 없는 여러 레이어 `.gpixel`은 레이어마다 부위), **스킨으로**는 스킨이 여럿인 첫 그룹(없으면 첫 그룹)에 그림 파일마다 새 스킨(이름 = 파일 이름)을 더해 크기가 같은 부위 — 없으면 가장 큰 부위, 그림이 더 크면 원래 그림 자리를 지키며 부위를 키움 — 에 넣고, 다른 `.gpixel` 그룹은 부위(이름·크기·위치·피벗·테두리·효과)가 같으면 그 스킨을 모두 더하고(물려받던 빈 칸은 그 그림으로 채움) 다르면 옆에 따로, **프레임으로**는 레이어 구조째 프레임을 이어 붙이고(이름·설정이 같은 레이어·그룹은 이어 쓰고 스킨은 이름으로 합침, 다르면 새 레이어, 태그·효과 범위는 밀림) 그림 파일은 같은 이름 레이어나 맨 위 일반 레이어(없으면 새 레이어)에 넣습니다. 레이어 하나뿐인 단순한 `.gpixel`은 그림 파일처럼 다룹니다. 캔버스가 커지면 부위 위치·피벗도 기준점만큼 옮겨 그림 자리를 지키고, 겹치는 레이어·스킨·태그 이름은 뒤에 숫자를 붙입니다. 창의 미리보기 아래에 무엇을 어떻게 유지하는지(예: "cobalt_ore_2.gpixel의 그룹·스킨을 유지합니다 — 그림은 \"ore\" 그룹의 새 스킨으로 넣습니다", 새 스킨이 들어갈 부위) 안내가 나옵니다. Unity 설정은 첫 `.gpixel`의 것을 가져오고(기본 피벗도 옮김), 내보내기 설정은 새 프로젝트 기본값입니다. 파일 브라우저에서 열려 있거나 저장하지 않은 변경이 메모리에 남은 파일은 디스크 대신 그 내용으로 합칩니다. 결과는 첫 파일 폴더의 `<이름>.gpixel`로 저장(+ 기본 내보내기)되고 바로 열립니다. 같은 이름 파일이 있으면 합치지 않고 알려 줍니다(지울 원본과 같은 이름은 됨).
  - **이미지 폴더 선택**(파일 우클릭): 그 파일이 실제로 든 폴더를 위 폴더 트리에서 펼쳐 고르고 잠깐 깜빡여 표시합니다(하위 폴더 포함으로 보던 파일의 위치 찾기). 목록은 그 폴더로 바뀌고 파일은 선택된 채로 남습니다.
  - **`.gpixel` 파일만 삭제 (휴지통)**(우클릭): 고른 항목의 `.gpixel` 프로젝트 파일만 앱 휴지통으로 보내고, 내보낸 PNG·`.meta`와 함께 고른 다른 파일은 그대로 둡니다(남은 PNG는 목록에 따로 보임). 일반 삭제처럼 묻지 않고 **Ctrl/⌘+Z**(마지막 삭제 되살리기)·앱 휴지통 보기로 되살리며, 열린 프로젝트 파일이면 수정됨으로 두고(저장하면 다시 만듦) 메모리에 남겨 둔 저장 안 한 문서면 메모리에서 버립니다. 고른 것에 `.gpixel`이 있고 일반 삭제가 그보다 더 지울 때(딸린 내보내기가 있거나 다른 파일도 고름)만 보입니다.
  - **앱 휴지통**: 목록에 작은 미리보기, 고른 항목은 오른쪽에 큰 미리보기(PNG·.gpixel 첫 프레임, 크기·원래 폴더)가 보입니다. 삭제(Delete, 여러 개 가능)와 합치기로 지운 원본은 묻지 않고 앱 자체 휴지통(`<설정 폴더>/Gpixel/Trash`)에 삭제 한 번씩 보관됩니다(딸린 PNG·`.meta` 포함). 파일 목록에서 **Ctrl/⌘+Z**로 마지막 삭제를 원래 자리에 되살리고, 우클릭 **앱 휴지통 보기…**에서 항목을 골라 되살리기(더블클릭)·영구 삭제·비우기를 합니다. 보관 정책은 둘 다 따로 끌 수 있습니다 — **기간 제한**(기본 꺼짐 = 기간 제한 없음, 켜면 N일 지난 항목 영구 삭제)과 **용량 제한**(기본 1GB, 넘치면 오래된 항목부터 영구 삭제). 시작할 때와 지울 때마다 적용되고, 휴지통 창(지금 개수·용량 표시)이나 **편집 > 환경 설정…**에서 바꿉니다. 원래 자리에 같은 이름 파일이 있으면 되살리지 않고 알려 줍니다.
- **팔레트 열**: 기본색/보조색(보조색 기본값 = 투명), 아래로 **팔레트 여러 개**를 쌓아 둡니다(넘치면 스크롤, 처음에는 DB32 하나). 팔레트마다 머리글(접기 화살표, 이름 — 두 번 눌러 바꾸기, 색 수, 메뉴 단추·우클릭 메뉴)이 있고, 메뉴의 동작은 **그 팔레트**에 합니다: 현재 색 추가·기본색 삭제·색상 순 정렬, .hex/.gpl 불러오기, 팔레트 웹(Lospec — 바꾸기/추가도 그 팔레트로), .hex 저장, 이미지에서 만들기, **팔레트 색으로 변환…**, 이름 바꾸기·위로·아래로·비우기·팔레트 삭제(하나 남으면 삭제 불가). 맨 아래 **새 팔레트**로 빈 팔레트("팔레트 2" …)를 더합니다. 마지막으로 누르거나 고친 팔레트가 **활성 팔레트**(머리글 아래 파란 줄)이고, 편집 메뉴의 "이미지에서 팔레트 만들기"·"팔레트 색으로 변환…"과 Claude 팔레트 도구는 활성 팔레트를 씁니다. 투명 칸은 **첫 팔레트 맨 앞에만** 있습니다. 기본색과 같은 칸은 모든 팔레트에서 흰 테두리, 보조색과 같은 칸은 파란 테두리, 둘이 같으면 반반 테두리(같은 색이 없으면 표시 없음). 팔레트 목록(이름·색·접힘·순서)은 설정에 저장됩니다(예전 버전의 팔레트 하나는 처음 실행 때 "팔레트 1"로 옮겨짐). 아래에 색 고르기(알파 막대, RGBA·HSV·HEX, 최근 색 16개).
  - **색 고르기 방식**: "색" 머리글 오른쪽 탭으로 바꿉니다(설정에 기억) — **사각형**(채도·명도 상자 + 세로 색상 막대, 기본) · **벌집**(육각형 칸 127개: 가운데 흰색에서 바깥으로 갈수록 진하고 어두운 색, 위 빨강부터 시계 방향, 아래 회색 13칸 — 누르거나 끌어서 고름) · **색상환**(바깥 고리 = 색상, 안쪽 사각형 = 채도·명도) · **슬라이더**(R·G·B·H·S·V 막대, 막대마다 지금 색에서 그 값만 바꾼 그라데이션). 어느 방식이든 지금 고르는 색(기본/보조)을 바꾸고, 알파 막대와 숫자 칸은 그대로입니다.
  - **팔레트 색으로 변환…**(팔레트 메뉴 단추, 편집 메뉴 = 활성 팔레트): 그림의 색을 팔레트 색으로 바꿉니다. 대상은 **현재 셀**(선택 영역이 있으면 그 안만) / **현재 레이어의 모든 프레임**(부위면 모든 스킨 셀) / **모든 레이어·프레임**(스킨 셀 포함, 잠긴 레이어는 건너뜀), 디더링은 **없음**(기본) / **순서 디더링(Bayer 4×4)**. 현재 프레임의 전·후 미리보기와 대상의 색 수(전 → 후)를 보여 줍니다. 투명이 아닌 픽셀마다 RGB를 팔레트의 투명이 아닌 색 중 가장 가까운 색으로 바꾸고(거리 = 사람 눈에 가깝게 빨강 양에 따라 R·B 무게를 바꾸는 가중 RGB "redmean", 같으면 팔레트 앞쪽 색), **알파는 그대로**, 완전 투명 픽셀은 건드리지 않습니다. 이미 팔레트에 있는 색은 디더링을 켜도 그대로입니다. 실행취소 한 단계.
  - **팔레트 웹(Lospec)…**: [lospec.com 팔레트 목록](https://lospec.com/palette-list)을 앱 안에서 둘러봅니다(인터넷 필요). 정렬(인기·다운로드순·최신·이름순), 색 수(전체/최대/최소/정확히 N), 태그(예: `gameboy`, `pico8`, Enter로 검색)로 거르고, 태그 칸에 팔레트 이름(예: `sweetie 16`)을 넣으면 그 팔레트를 맨 위(별 표시)에 보여 줍니다. 목록의 각 팔레트 색은 팔레트 칸 크기(14px)로 늘어놓습니다(많으면 줄바꿈). 목록 끝까지 내리거나 **더 보기**로 다음 쪽을 불러옵니다. 팔레트를 고르면 아래 왼쪽에 팔레트 칸 크기로 색을, 오른쪽에 그 팔레트로 그린 예시 그림(Lospec 예시, 픽셀 그대로 정수 배율, 여러 장이면 띠를 장 수만큼 똑같이 나눈 고정 칸으로 보이고, 칸에 마우스를 올리면 그 그림이 띠 전체로 커져 크게 보임 — 칸은 그대로라 옆 칸으로 옮기면 바로 그 그림, 아래 막대가 지금 칸 표시)을 보여 줍니다. 고른 팔레트는 **팔레트로 쓰기**(지금 팔레트를 바꿈, 목록 더블클릭과 같음)·**현재 팔레트에 추가**(겹치는 색 제외)·**.hex로 저장**·**Lospec에서 보기**. 팔레트 저작권은 각 작성자에게 있습니다.
- **숫자 칸(공통)**: 위/아래 단추 없이 **좌우로 끌면** 값이 바뀝니다(3px마다 한 칸, Shift = 10배 느리게, Ctrl/⌘ = 10칸씩). 끌다가 화면 끝에 닿으면 커서가 반대편 끝으로 넘어가 계속 끌 수 있고, 끌지 않고 클릭하면 글자로 입력합니다. 프로젝트 설정을 끌어 바꾸면 실행취소 한 단계로 묶입니다.
- **우클릭·단추 메뉴(공통)**: 앱 전체에서 한 번에 하나만 열립니다(다른 창 것 포함). 바깥을 누르거나(어느 창이든) 휠, Esc, 창 전환·이동·크기 바꿈에 닫히고, 연 단추를 다시 누르면 닫힙니다.
- **캔버스**: 현재 프레임 한 장(보이는 레이어 합성)을 보여 주고 현재 레이어의 셀에 그립니다. 부위 레이어를 고르면 그 부위만 자기 크기로 보이고, 프레임의 나머지(다른 그룹·같은 그룹의 다른 부위·일반 레이어)는 부위 칸 안팎에 **반투명하게** 비쳐 맞춰 그릴 수 있습니다. 그룹 레이어를 고르면 부위를 끌어 배치합니다. 1~64배 정수 확대, 체커 배경, 픽셀/타일 격자, 타일 모드(5×5 반복 — 한 변이 128px 넘는 큰 그림은 3×3, 이어 그리기), 대칭 안내선, 피벗, 선택 영역, 양파 껍질, H를 누르는 동안 이전 프레임 보기.
- **타임라인(아래)**: 미리보기를 재생하면 지금 보이는 프레임 열(머리글 + 칸)이 초록 외곽선 네모로 표시됩니다. 행 = 레이어(눈·자물쇠·접기·fx·스킨 칩·프레임 끝 복사/더하기 단추처럼 누르면 바로 동작하는 곳은 마우스를 올리면 손 모양 커서 — 눈·자물쇠 아이콘: 잠근 레이어만 그릴 수 없고, 숨긴 레이어에는 그릴 수 있음: 일반 레이어는 편집하는 동안 캔버스에만 반투명하게 보이고 미리보기·내보내기에는 나오지 않음, 불투명도, 이름, 그룹은 삼각형으로 접고 펼치며 부위는 그 아래 들여쓰기), 열 = 프레임(번호·길이·실시간 썸네일), 위쪽 띠 = 태그(색 괄호로 프레임을 묶어 보임). 도구 단추 없이 **우클릭 메뉴**로 다룹니다(메뉴는 고른 것 대상, 맨 위에 고른 것 표시 — 프레임 머리글: 태그 만들기, 빈 프레임·복제·삭제·옮기기·길이, 프레임 복사·잘라내기·붙여넣기, 피벗·칸 이름 / 셀: 셀 지우기, 이전 프레임 그림 복사, 셀 복사·잘라내기·붙여넣기, 효과 추가, 태그·빈 프레임·복제·길이, 피벗·칸 이름 / 레이어 이름: 이름·불투명도·효과·보이기·잠금·부위 크기·위치·새 레이어·그룹·부위·복제·순서·병합·삭제 / 빈 곳: 새로 만들기). 재생은 미리보기에서 합니다.
  - **다음 프레임 칸**(마지막 프레임 뒤): 머리글 칸 더하기 아이콘 = 빈 프레임 추가, 그 아래 셀 칸 복사 아이콘 = 마지막 프레임을 복사해 추가(누른 행의 레이어가 골라짐).
  - **고르기(한 번에 한 종류)**: **프레임 머리글**을 누르면 그 프레임(머리글에 파란 테두리, 그 열 칸은 옅게), **레이어 이름**을 누르면 그 레이어(이름 칸에 파란 테두리), **셀**을 누르면 그 칸(파란 테두리)이 골라지고, 누른 것이 현재 프레임·레이어가 됩니다. 고르지 않은 머리글·이름·셀을 누른 채 끌면 옅은 파란 **사각형**이 포인터를 따라오며 닿는 것이 모두 골라집니다(머리글 = 여러 프레임, 이름 = 여러 레이어, 셀 = 행 × 프레임 묶음 — 묶음 둘레에 파란 테두리, 가장자리에서는 자동 스크롤). Shift+클릭 = 마지막으로 누른 것부터 범위로 넓히기, Ctrl/⌘+클릭 = 프레임·레이어를 하나씩 더하고 빼기(떨어져 있어도 됨). 눈·자물쇠·접기 삼각형·fx·스킨 칩·자동 배치 마름모는 고르지 않고 제 동작만 합니다. 빈 곳을 누르면 선택이 풀려 현재 칸만 남습니다. 상태 표시줄에 고른 것과 Delete가 할 일이 나옵니다.
  - **방향키**(타임라인을 누른 뒤): ←→ = 옆 프레임, ↑↓ = 옆 레이어로 선택이 옮겨 갑니다(현재 칸도 따라감 — 캔버스 그림을 밀지 않음). 프레임을 골라 둔 상태면 ←→가 프레임 선택을, 레이어를 골라 둔 상태면 ↑↓가 레이어 선택을 옮기고, 그 밖에는 칸 하나를 옮깁니다. **Shift+방향키**는 끌어서 고르듯 넓힙니다(프레임 범위 / 레이어 범위 / 칸 묶음).
  - **통째로 복사·붙여넣기**(타임라인을 누른 뒤 Ctrl/⌘+C → Ctrl/⌘+V): 프레임(머리글)을 골라 복사하면 붙일 때 고른 프레임 뒤에 **새 프레임**으로, 레이어(이름)를 골라 복사하면 **새 레이어**로 생깁니다(원래 레이어 바로 위, 그룹은 부위까지 — 실행취소 1단계, 새로 생긴 것이 골라짐). 새 레이어 이름은 끝 숫자를 자릿수 그대로 1 올립니다(`item_1` → `item_2`, `tile_009` → `tile_010`, 숫자가 없으면 `_1`, 이미 있는 이름은 건너뜀; 레이어 메뉴 **복제**도 같은 이름 규칙). 선택은 한 번에 한 종류라, 프레임과 레이어를 차례로 누르면 마지막에 누른 쪽만 골라져 복사됩니다. 프레임 열 끝의 **복사 아이콘**은 어느 줄에서 눌러도 프레임 전체(모든 레이어)를 복사하므로, 마우스를 올리면 그 열의 복사 아이콘이 위아래로 함께 강조됩니다.
  - **Delete(⌫)**(타임라인을 누른 뒤): 고른 종류대로 — **프레임** → 그 프레임들 삭제, **레이어** → 그 레이어들 삭제(그룹은 부위까지, 그룹과 그 부위를 함께 골라도 한 번만 셈), **셀** → 그 칸들의 그림만 지우기(그룹 행은 그 부위들, 프레임·레이어는 남음). 모두 실행취소 한 단계이고 상태 표시줄에 "프레임 2개 삭제"·"레이어 3개 삭제"·"셀 6칸 지움"처럼 알립니다. 프레임·레이어를 하나도 남지 않게는 지우지 않고 알려 줍니다. 캔버스·글 입력란에 포커스가 있으면 그쪽 Delete(선택 영역 지우기·글자 지우기)가 그대로입니다.
  - **우클릭**: 고르지 않은 머리글·이름·셀을 우클릭하면 먼저 그것을 고르고(테두리가 보임), 고른 것 위면 선택을 그대로 둔 채 그 종류의 메뉴를 엽니다. 메뉴 맨 위에 "프레임 1~3 선택됨"처럼 고른 것이 보이고, 프레임 메뉴 **삭제**는 고른 프레임 모두, 레이어 메뉴 **삭제**는 고른 레이어 모두, 셀 메뉴 **셀 지우기**는 고른 칸 모두에 합니다(옆에 Delete 단축키 표시).
  - **순서 바꾸기(끌기, 실시간 미리보기)**: **이미 고른** 프레임 머리글이나 레이어 이름을 누른 채 4px 넘게 끌면 그 열·행이 떠서 포인터를 따라오고 다른 열·행이 비켜 서며 놓을 자리가 열립니다(이어진 고른 프레임은 덩어리째, 같은 단계에서 이어진 고른 레이어도 덩어리째, 그룹은 부위 행과 함께, 부위는 같은 그룹 안에서만, 가장자리에서는 자동 스크롤). 끌지 않고 떼면 그것 하나만 골라집니다. 놓으면 실행취소 한 단계, Esc는 취소(제자리로 돌아감). 앱의 모든 끌어서 순서 바꾸기 목록(합치기 순서, 레이어 효과 목록, 내보내기 정렬 목록)이 같은 모양·동작입니다.
  - **태그**: 고른 범위에서 우클릭 **태그 만들기**로 묶습니다. 태그 상자 안쪽 양 끝(손잡이)에 마우스를 대면 ↔ 모양이 되고 끌어서 범위를 바꿉니다(태그가 겹쳐 있어도 각 상자 안쪽 끝을 잡으면 그 태그만 바뀜, 실행취소 1단계). 태그를 고르고 미리보기에서 재생하면 그 태그 안에서 반복합니다(재생 중에 태그를 바꿔도 바로 반영).
  - **셀 묶음 옮기기·복사**: 여러 칸을 골라 둔 뒤 그 안을 다시 눌러 끌면 묶음째 옮기고(끌지 않고 놓으면 그 칸 하나만 골라짐, 한 칸에서 끌면 범위 고르기), ⌥/Alt(또는 Ctrl/⌘)를 누른 채 놓으면 복사합니다. 놓을 자리가 파란 칸으로 미리 보이고, 마지막 프레임을 넘기면 프레임이 늘어납니다. 셀 크기·종류가 다른 행(예: 머리 칸을 몸 행에)으로는 옮기지 않고 알려 줍니다(그림이 사라지지 않게). 그룹 행 칸은 그 부위들째 옮깁니다(부위 수·크기가 같은 그룹으로만). 고른 프레임 번호를 다시 눌러 끌면 프레임 순서가 바뀝니다.
  - **복사·붙여넣기**: 칸을 골라 Ctrl/⌘+C(또는 X), 붙일 칸을 클릭하고 Ctrl/⌘+V — 클릭한 칸을 왼쪽 위로 같은 모양(행 × 프레임)으로 덮어씁니다. 프레임 머리글로 골랐으면 프레임 전체를 복사하고(잘라내기 = 그 프레임 삭제) 붙이면 고른 프레임 뒤에 끼워 넣습니다. 레이어 이름으로 골랐으면 그 레이어들의 모든 프레임 칸을 복사합니다(잘라내기 = 그 칸들 비우기). 타임라인에 복사해 둔 것이 없으면 보통 그림 붙여넣기입니다. 앞 프레임 그림을 그대로 가져오려면 셀 우클릭 "이전 프레임 그림 복사". 프레임 번호 더블클릭 = 프레임 길이.
  - **레이어 효과(비파괴)**: 레이어 이름 우클릭 **효과…**(효과가 있으면 `효과… (N)`, 이름 칸 오른쪽에 **fx** 표시 — 모두 꺼 두면 흐리게). 셀 픽셀은 그대로 두고 보일 때만 입히므로 나중에 그린 것에도 자동으로 붙습니다. 일반 레이어·부위는 그 셀에, **그룹은 부위들을 합친 모양**에 입힙니다(예: 그룹 외곽선 = 캐릭터 전체 둘레 한 줄, 부위 사이엔 선 없음). 효과는 위에서부터 차례로 쌓이고(예: 외곽선 → 그림자면 외곽선까지 그림자) 하나씩 켜고 끕니다. 모두 픽셀 단위(번짐·안티에일리어싱 없음):
    - **효과 색 고르기**: 일반색의 색 칸을 누르면 별도 대화상자 대신 **왼쪽 메인 색 편집기와 동일한 사각형·벌집·색상환·슬라이더 + 오른쪽 메인 팔레트·최근 색·스포이드**를 나란히 둔 팝업이 바로 열립니다. 색상·팔레트 색을 고르는 동안 캔버스와 효과 미리보기가 즉시 바뀝니다. 색 설정마다 **일반색 / 그라데이션**을 바꿀 수 있고, **그라데이션을 고르는 즉시** 별도 팝업이나 "정지점 편집" 단추 없이 그 효과 설정 안에 편집기가 펼쳐집니다. 이 편집기는 메인 그라데이션 도구와 같은 색·불투명도 정지점, 위치, 보간·디더에 효과용 각도를 더해 사용합니다. 색·불투명도 정지점의 알파는 해당 픽셀의 효과 세기에 반영됩니다.
    - **외곽선**: 색, 두께 1~3px, **4방향(십자)** / **8방향(모서리 포함)**, **바깥**(그림 밖 투명 자리에, 두께만큼 커짐) / **안쪽**(가장자리 픽셀을 칠함, 알파 그대로).
    - **그림자**: 그림 모양 그대로(단단한 그림자) 한 색(알파 = 진하기)으로 X·Y px(±16) 옮겨 뒤에 깝니다. **디더**(없음 / 25% / 50% 바둑판 / 75%)를 고르면 반투명 대신 불투명한 그림자 색을 4×4 Bayer 무늬 칸에만 깝니다(픽셀아트식 디더 그림자, 무늬는 효과 원본 왼쪽 위 기준이라 캔버스·부위 아틀라스에서 같음). 디더가 없던 예전 파일은 그대로 반투명입니다.
    - **가장자리 빛·그늘**: 빛이 오는 쪽(8방향)을 향한 가장자리에서 **범위** 1~16px만큼 빛 색, 반대쪽에 그늘 색을 덧칠합니다(알파 = 세기, 0 = 안 칠함).
    - **색 덮기**: 보이는 픽셀을 일반색 또는 **공간 그라데이션** 쪽으로 **양** 0~100% × 선택한 색의 알파만큼 섞습니다. **섞기**는 덮기·곱하기·스크린이고 원본 픽셀의 투명도는 그대로입니다. 예전 `그라데이션 덮기` 프로젝트는 같은 각도·색·디더·세기의 색 덮기로 자동 변환되어 모습이 유지됩니다.
    - **안쪽 빛**: 그림 가장자리에서 안쪽으로 **두께** 1~8px(모서리 포함 8방향 거리)까지 한 색을 섞습니다. **세기** %, **섞기**(덮기 / 곱하기 / 스크린, 기본 스크린), **안쪽으로 갈수록 약하게**(1px마다 한 단계씩, 끄면 두께 전체 같은 세기). 크기는 그대로입니다.
    - **색 바꾸기(팔레트 스왑)**: 색 쌍 목록 **바꿀 색 → 바뀐 색**(줄마다 색 칸 + HEX, 빼기 단추). **쌍 추가**(아직 바꾸지 않는 가장 많이 쓰인 색부터), **그림에서 색 가져오기**(이 프레임 그림에 쓰인 색을 많이 쓰인 순으로 — 누르면 그 색의 쌍 추가, **모두 추가**). 보이는 픽셀의 RGB가 바꿀 색과 같으면(**허용 차이** 0~255 = 채널마다 차이, 0 = 정확히 같은 색만) 바뀐 색으로 — 투명도 = 원래 투명도 × 바뀐 색 투명도(투명으로 바꾸면 지워짐). 위의 쌍이 먼저이고 한 번만 바뀌어 두 색 맞바꾸기도 됩니다. 스킨 색 바꾸기(빨간 옷 → 파란 옷)를 셀을 고치지 않고 할 때 씁니다.
    - **색조 보정**: 방식 **흑백**(밝기 0.299R + 0.587G + 0.114B 쪽으로 양 %) / **세피아**(양 %) / **색조 이동**(색상 ±180°) / **밝기·대비**(각 ±100%) / **채도**(±100%, −100 = 흑백). 보이는 픽셀의 색만, 투명도는 그대로입니다(색 수는 줄이지 않음).
    - **반사**: 그 프레임 그림을 위아래로 뒤집은 복사본을 아래(바닥·물, 기본) 또는 위(천장)에 **간격** 0~32px 띄워 뒤에 깝니다. **높이** 1~100%(그림 높이의 몇 %가 비칠지, 그림 쪽 줄부터), **불투명도** 시작 % → 끝 %(그림 쪽 줄 → 끝 줄), **디더로 흐리기**(반투명 대신 4×4 Bayer 무늬로 덜어 냄), **색 입히기**(그 색 쪽으로 물들임, 색의 투명도 = 세기, 기본 0 = 안 물들임 — 물 파랑 등), **물결** 0~3px(줄마다 가로로 흔듦, 고정 무늬). 아래로 간격 + 비친 높이만큼 번지므로 부위 아틀라스 스프라이트도 그만큼 커집니다.
    - **움직이는 효과(터지기 ~ 홀로그램)**: 모습이 효과의 **프레임 범위** 안 진행 t = (프레임 − 시작) / (끝 − 시작)에 따라 바뀝니다 — 범위 첫 프레임 = 시작(t = 0), 마지막 프레임 = 끝(t = 1), "모든 프레임"이면 애니메이션 전체. 범위를 늘리면 느려지고 줄이면 빨라집니다(한 프레임이면 움직이지 않음). 공통 설정 **빠르기**(처음 빠르게 / 일정하게 / 천천히 시작 / 천천히 시작·끝)와 **반복**(한 번 / N번 반복 / N번 왕복, 범위 안에서).
      - **터지기**: 보이는 픽셀이 "펑" 하고 바깥으로 튀어 날아가며 사라집니다(셀 그림은 그대로, 범위 첫 프레임은 원래 그림과 똑같음). 설정 = **거리**(끝까지 날아가는 px, 1~128 — 가장 바깥 조각 기준, 중심 쪽 조각은 그 40%까지 덜 날아가 그림이 통째로 부풀며 흩어짐), **중심**(가운데 / 피벗 / 아래 가운데 / 직접 X·Y), **흩어짐** 0~100%(방향 ±90°×%, 빠르기 최대 60% 느리게 — 시드로 정해진 무작위), **중력**(끝에서 더 떨어지는 px, 음수 = 떠오름, 위치 += 중력 × 진행²), **조각 크기** 1~4px(+ 끝으로 갈수록 작게), **사라짐**(켜면 시작 %부터 알파가 줄어 끝에서 투명), **번쩍임**(시작 다음 0~8프레임 동안 조각을 한 색 쪽으로 — 점점 약하게), **원본 남기기**(켜면 원래 그림은 남고 복사본이 날아감), **시드**(주사위 단추 = 다른 흩어짐). 빠르기 기본 = 처음 빠르게. 조각은 정수 픽셀에 놓이고 알파만 흐려집니다(번짐 없음). 각 프레임의 그림이 조각이 되므로 범위의 프레임마다 그림이 있어야 합니다(빈 프레임이면 터질 것도 없음). 그림 밖으로 날아간 조각은 캔버스에서 잘리고, 부위 아틀라스에서는 거리(+ 중력 쪽)만큼 스프라이트가 커집니다.
      - **빛 지나가기**: 빛 띠가 보이는 픽셀 위를 **각도**(지나가는 방향, 기본 45° = 왼쪽 아래 → 오른쪽 위) 쪽으로 지나갑니다(동전·단추의 반짝임). 진행 0에는 그림 한쪽 바로 밖, 1에는 반대쪽 바로 밖이라 시작·끝 프레임은 그대로. 설정 = **폭**(px), **색**(기본 흰색), **세기**(%), **부드러움**(딱딱하게 / 가장자리 1px·2px 계단식). 보이는 픽셀만 밝게(스크린) 하고 투명한 곳·투명도는 그대로입니다.
      - **늘었다 줄기**: 젤리처럼 출렁이다 원래 모양으로 돌아옵니다. 가로 배율 = 1 + 가로 세기 × f(t), 세로 = 1 − 세로 세기 × f(t); f는 튕김 횟수만큼 출렁이며 줄어드는 사인(시작·끝 = 0, 첫 봉우리 = 1). **가로 세기**·**세로 세기**는 각각 0~50%(0 = 그 축 고정)입니다. 기준점(아래 가운데 = 발 고정 / 가운데 / 피벗), 순서(옆으로 먼저 / 위로 먼저), 튕김 1~3번을 정합니다. 이전 프로젝트의 단일 세기는 양쪽에 동일하게 적용됩니다.
      - **그라데이션 변화**: 공용 그라데이션 편집기에서 원하는 만큼 **색·불투명도 정지점**을 놓으면 효과 범위 첫 프레임은 왼쪽 끝 색, 마지막 프레임은 오른쪽 끝 색이고 중간은 정지점 위치대로 그림 전체 색이 변합니다. **부드럽게**는 프레임마다 한 색, **단계**는 가까운 정지점 색, **디더**는 전환 중인 두 색을 2×2·4×4 픽셀 무늬로 섞습니다. **세기**·**섞기**(덮기·곱하기·스크린)와 움직이는 효과 공통의 빠르기·반복·왕복을 사용합니다.
      - **피격 번쩍임**: 보이는 픽셀이 한 색(기본 흰색, **흰색·빨강** 단추)으로 번쩍입니다(투명도는 그대로). 진행 u를 **횟수**(1~8)로 나눈 한 번 안의 자리 f = frac(u × 횟수): **모양** 꽉 채움이면 f < ½ 동안 **세기**(0~100%)만큼 색, 점점 엷어짐이면 세기 × (1 − f). 범위 첫 프레임에서 바로 번쩍이고 마지막 프레임은 늘 원래 그림입니다.
      - **깜빡이기**: 보였다 숨었다를 되풀이합니다(무적 시간). **간격** = 프레임 수로(범위 첫 프레임부터 보임 N·숨김 M프레임, 1~16) 또는 범위 안 횟수로(범위의 프레임을 보임·숨김 2N칸으로 고르게 나눠 N번 숨음, 첫 프레임은 보임). **숨김 방식** = 완전 투명 / 반투명(남는 불투명도 %) / 디더 50%(바둑판 칸만 남김 — 원본 왼쪽 위 기준이라 무늬가 그대로).
      - **흔들기**: 그림 전체를 정수 픽셀만큼 옮겨 떱니다. **방향**(가로 / 세로 / 둘 다), **세기**(최대 옮김 1~32px — 그 축으로 여백), **횟수**(1~16), **줄어듦**(크기 × (1 − u)), **움직임** 무작위(시드로 정한 값, 한 번에 두 번 바뀜) / 규칙적(sin(2π·횟수·u), 둘 다면 세로는 두 배 빠르게 — 8자). |옮김| ≤ 세기, 시작·끝 프레임은 제자리.
      - **둥실둥실**: 사인으로 부드럽게 오르내립니다(떠 있는 아이템). 옮김 = round(**높이** × sin(2π × **횟수** × u))px(위아래면 위로 먼저 / 좌우), 높이 1~32px(그 축으로 여백), 횟수 1~8. 범위 처음과 끝(u = 0·1)이 똑같아 되풀이해도 끊기지 않습니다.
      - **나타나기 / 사라지기**: 한 효과에 **모드**(나타나기 = 범위 첫 프레임이 비어 있고 끝에서 그림 그대로, 사라지기 = 반대)와 **방식**: 투명도(알파 × 보임) / 디더(4×4 Bayer 순서 디더, 문턱 (b + ½)/16 < 보임인 픽셀만) / 쓸기(**쓸기 시작** 위·아래·왼쪽·오른쪽에서 선이 보이는 그림을 지나감, **가장자리** 딱딱하게·디더 1px·2px, 사라지기면 그 쪽부터 지워짐) / 픽셀 흩어짐(**시드**로 정한 무작위 차례). 디더·쓸기·흩어짐은 픽셀이 켜지고 꺼지기만 합니다(반투명 없음).
      - **녹아내리기**: 보이는 픽셀이 열마다 아래로 흘러내려 사라집니다. 열마다 시드로 늦게 시작(불규칙함 × 0.5까지)·느리게(최대 50%) — 그 열의 진행 q, 내려감 = **거리**(1~128px, 아래로 여백) × 빠르기 × q². **늘어짐**이면 열 아래쪽 픽셀일수록 더 내려가(40% → 100%) 사이를 위 픽셀 색으로 채운 흐른 자국, **사라짐**이면 q가 0.65를 넘으며 투명해져 범위 끝에서 모두 사라집니다. **불규칙함** 0~100%, **시드**.
      - **회전**: 범위 동안 **기준점**(가운데 / 아래 가운데 / 피벗)을 중심으로 **각도**(0~1440°, 기본 360 = 한 바퀴)만큼 **방향**(시계 / 반시계)으로 돕니다. RotSprite 방식 — 보이는 그림을 Scale2x(EPX)로 키워(한 변 128px 이하 8배, 256px 이하 4배, 512px 이하 2배) 결과 픽셀마다 가운데 점을 거꾸로 돌려 최근접으로 집습니다(새 색·반투명 없이 선이 덜 깨짐). 90°의 배수는 손실 없이 옮기고 360°의 배수는 원래 그림 그대로. 여백 = 돌린 그림이 닿을 수 있는 만큼.
      - **잔상**: 앞 프레임 그림에 잔상을 제외한 다른 효과를 **그 프레임의 진행대로** 적용한 뒤 현재 그림 뒤에 점점 옅게 깝니다. 앞뒤 효과 목록 순서와 관계없이 흔들기·둥실둥실·회전 등으로 움직인 과거 위치를 따라갑니다. k번째 잔상 = 프레임 (지금 − k × **간격**), 불투명도 = **불투명도** × (개수 − k + 1) / 개수. **개수** 1~8, 간격 1~8프레임, **색 입히기**(색 알파 = 세기). 잔상 자체를 반복 적용하지 않고 효과의 **프레임 범위 안 프레임만** 쓰므로 범위 첫 프레임에는 잔상이 없습니다.
      - **색 순환**: 그림에서 목록의 i번째 색(RGB가 같은)인 픽셀을 (i + k) mod n번째 색으로 바꿉니다(투명도는 그대로, 목록에 없는 색은 그대로 — 물·불·네온). **색** 2~8개(색마다 빼기 단추, **색 추가**, **그림에서 색 가져오기**), **칸 수**(범위 동안 넘어가는 횟수, k = ⌊진행 × 칸 수⌋ — 색 개수의 배수면 끝이 처음과 같아 되풀이해도 이어짐), **방향**(앞으로 / 거꾸로).
      - **충격파 고리**: **중심**(가운데 / 피벗 / 아래 가운데 / 직접 X·Y) 픽셀에서 고리가 반지름 round(**최대 반지름** × 진행)까지 퍼집니다(기본 처음 빠르게). **두께** 1px = 중점 원 그리기(빈틈·겹침 없는 픽셀 원), 그보다 두꺼우면 그만큼 안쪽으로 채운 고리. **색**(알파 = 진하기), **사라짐**(알파 × (1 − 시간) — 빠르기 곡선 없이), **위치**(그림 앞 / 뒤). 범위 첫 프레임은 반지름 0이라 보이지 않고, 사방으로 최대 반지름만큼 여백이 생깁니다.
      - **홀로그램**: 보이는 픽셀을 SF 홀로그램 투사 영상처럼 바꿉니다(셀 그림은 그대로). **색**(기본 하늘색 #50DCFF) 쪽으로 **색 세기**(기본 85%)만큼 — 밝기 L = 0.299R + 0.587G + 0.114B를 그 색의 명암(L ≤ 192: 색 × (0.3 + 0.7 × L/192), 그 위는 흰색 쪽으로 최대 60%)으로 바꾸므로 모양·명암 순서가 그대로인 한 색 그림이 됩니다. **주사선**: **간격** 2~6줄마다 한 줄을 **세기** %만큼 **어둡게 / 투명하게**(원본 위 기준, 0% = 끔), **흐르기**면 범위 동안 한 간격 아래로 흘러(⌊진행 × 간격⌋) 되풀이해도 이어집니다(반복 N번이면 N번 흐름). **밝은 띠**(켜고 끔): **두께** px의 띠가 범위 처음 그림 바로 위에서 끝에 바로 아래로 지나가며 색과 흰색 사이 색으로 밝힙니다(스크린, **세기** %). **투명도**(기본 75%, **디더**면 반투명 대신 4×4 Bayer 칸만 남김). **깜빡임**: 프레임마다 **빈도** % 확률로 불투명도가 세기 × (50~100%)만큼 내려갑니다. **글리치**: 프레임마다 **빈도** % 확률로 1~3개 가로 조각(1~3px)이 좌우로 1~**최대 밀림** px 밀리고, **RGB 분리**면 그 프레임에 빨강은 왼쪽·파랑은 오른쪽 1px 이웃 값을 씁니다. **테두리 빛**(켜고 끔): 그림 밖 4방향 1px에 색 × **세기** %(× 투명도·깜빡임, 디더면 무늬). **시드**(주사위 단추). 빠르기·반복은 주사선 흐름과 띠에만 쓰이고 깜빡임·글리치는 시드와 범위 안 프레임 번호로 정해져, 같은 프레임·설정·시드면 캔버스·프레임 시트·부위 아틀라스·GIF가 늘 같습니다. 여백 = 좌우로 최대 밀림(글리치 빈도 0이면 없음), 테두리 빛이면 사방 1px 더. 배경색 없이 GIF로 내보내면 알파 128 미만이 투명이 되므로 옅은 테두리 빛은 디더를 켜야 GIF에도 보입니다.
    - **창**: 맨 왼쪽 = **효과 종류** 상자 목록(세로 스크롤, 두 줄 — 상자마다 위 = 지금 프레임 그림에 그 효과를 기본 설정으로 입힌 미리보기(그림이 비었거나 128px보다 크면 작은 견본 공), 아래 = 이름. 움직이는 효과는 미리보기가 계속 돌아감. 마우스를 올리면 그 효과가 하는 일 한 줄 설명). 상자를 **두 번 누르면** 목록 끝에, **효과 목록으로 끌어 놓으면** 놓은 자리에 추가합니다(끄는 동안 목록 테두리가 파랗게). 그 옆 = **추가 범위**("모든 프레임" 체크 또는 시작~끝 프레임), 효과 목록(체크 = 켜기, 고르고 **Delete** = 삭제, **삭제·위로·아래로·영구 적용**)과 고른 효과 설정(맨 위 = **프레임 범위**: "모든 프레임" 체크 또는 시작~끝 프레임 — 체크를 풀면 지금 프레임 하나로 시작), 오른쪽 = 지금 프레임의 **전·후 미리보기**(폭 고정, 같은 정수 배율, 고른 프레임이 각 효과의 범위 안일 때만 적용). 효과를 고르면 정적인 효과도 그 범위 처음부터 바로 재생합니다. **고른 효과 범위만**은 기본으로 켜져 있고, 끄면 프레임 늘리기로 더해질 사본까지 포함한 전체 프레임을 재생합니다. **재생 / 멈춤**으로 켜고 끄며, 끝 프레임은 조금 더 보여 준 뒤 처음으로 돌아가고 **끝에서 바로 처음으로**를 켜면 멈칫 없이 곧바로 첫 프레임으로 이어 반복합니다(두 체크 상태는 앱을 켜 둔 동안 기억). 미리보기 아래 **프레임 줄** = 프레임마다 그 프레임 범위 안의 효과를 입힌 작은 그림(가로로 꽉 차면 다음 줄로 줄바꿈, 3줄이 넘으면 세로 스크롤)에 고른 효과의 프레임 범위(효과를 고르지 않았으면 추가 범위)가 파랗게, 범위 밖은 어둡게, 미리보기 프레임은 흰 테두리로 보입니다. 칸을 누르면 그 프레임을 미리보기에(재생 멈춤), **끌면 프레임 범위**가 정해집니다(설정의 숫자 칸과 같은 값 — 모든 프레임을 덮으면 "모든 프레임"). 설명 글은 화면에 늘어놓지 않고 모서리가 둥근 **i** 표시(효과 종류 제목 옆, 재생 줄 끝, 설정의 프레임 범위 줄 끝)에 마우스를 올리면 풍선으로 보입니다. 고치는 동안 캔버스·타임라인 썸네일에도 바로 보이고, **확인** = 창에서 고친 것 전체가 실행취소 한 단계, **취소**·창 닫기 = 원래대로. 레이어 복제는 효과도 복사하고, **아래와 병합**은 위 레이어의 효과를 프레임마다(그 프레임 범위대로) 구워 넣습니다.
    - **프레임 늘리기(효과 창)**: 고른 효과 설정의 범위 줄 아래 **프레임 수**(단위 프레임, 우클릭 = 그대로·×2·×3·8·12·16·24·32)와 **늘리기** 방법으로, 효과를 짜는 동안 범위의 프레임 수를 늘립니다(예: 4프레임 애니메이션에 12프레임짜리 터지기). **원래 프레임으로**(범위 뒤에 프레임이 있으면 기본) = 범위 끝을 뒤에 이미 있는 프레임까지 넓힐 뿐 프레임은 더하지 않습니다(프레임 수 최대 = 마지막 프레임까지, 옆에 "뒤에 프레임 N개 있음" — 더 늘리려면 다른 방법). 나머지는 확인할 때 프레임을 **더합니다** — 범위 n개 → N개(최대 256): **같은 비율로**(자리 k = 원래 ⌊k·n/N⌋ — 2배면 프레임마다 두 번), **첫 프레임으로**(첫 프레임을 앞에 N−n개 더), **마지막 프레임으로**(마지막 프레임을 뒤에 더), **반복**(1, 2, …, n, 1, 2, …). 더한 프레임은 원래 프레임의 사본입니다(모든 레이어·부위·스킨 셀, 길이·피벗 같음, 칸 이름은 비워 이름 규칙). "모든 프레임"이면 애니메이션 전체를 늘립니다. 미리 보는 동안 전·후 미리보기·재생·진행 %와 프레임 줄은 늘린 뒤 차례를 보이고(캡션에 `프레임 8/12 · 원래 프레임 3 사본`, 더해질 사본 칸은 점선 테두리), 프레임 줄에서 효과를 고른 채 범위 끝을 **마지막 칸 너머로 끌면** 점선 빈 칸(번호 5, 6, …)이 생기며 끈 칸 수만큼 늘립니다(방법은 늘리기 상자 값). **확인** = 프레임 늘리기 + 효과 확정이 실행취소 한 단계(상태 표시줄에 "프레임 1~4: 4개 → 12개로 늘림 (같은 비율로)"), 취소 = 아무것도 바뀌지 않음. 태그와 모든 레이어 효과의 범위는 프레임 번호를 따라갑니다 — 늘린 범위를 덮으면 늘어나고 뒤쪽은 밀립니다. 한 번에 한 범위만 늘립니다.
      - 프레임 추가 예정과 각 효과 범위는 독립적으로 유지됩니다. 예를 들어 안쪽 빛을 `1~10`으로 끌어 10프레임을 잡은 뒤 색조 보정을 사본 칸 `1~2`로 끌면 전체와 안쪽 빛은 `1~10` 그대로이고 색조 보정만 `1~2`가 됩니다. 이어 색조 보정을 기존 끝 너머인 `1~15` 또는 `2~14`로 끌면 공용 타임라인은 각각 15·14프레임까지 더 늘어나되, 안쪽 빛은 `1~10`에 그대로 남고 색조 보정만 끈 범위를 가집니다. 다른 효과 범위를 바꿔도 먼저 정한 범위나 추가 프레임은 사라지거나 줄지 않으며, 설정에는 `추가 유지 · <효과 이름> +N` 또는 범위가 함께 타임라인을 늘렸으면 `추가 유지 · 전체 N프레임`으로 표시됩니다.
    - **효과만큼 캔버스 확대(효과 창)**: 체크하면 **확인** 또는 **영구 적용** 때 현재 레이어의 켜진 효과가 모든 적용 프레임에서 캔버스 밖으로 나간 실제 픽셀을 계산해 캔버스를 늘립니다. **최소한으로** = 나간 방향만 필요한 픽셀 수만큼, **비율 유지** = 효과를 모두 담는 범위에서 원래 캔버스 가로세로 비율을 유지하도록 반대 축 여백도 늘립니다. `32×32 → 46×40`처럼 결과 크기가 바로 표시되고, 이미 효과가 안에 들어가면 바꾸지 않으므로 같은 효과로 다시 실행해도 계속 커지지 않습니다. 그림 자체 크기는 바꾸지 않고 모든 프레임의 일반 레이어·부위 위치·스킨·기본/프레임 피벗을 새 캔버스 자리로 함께 옮깁니다(부위 크기·부위 피벗·9-slice는 그대로). 효과 변경·프레임 늘리기·캔버스 확대는 **실행취소 한 단계**입니다. 기본은 꺼짐입니다.
    - **타임라인 효과 줄(영상 편집처럼)**: 효과가 있는 레이어 행 아래에 효과마다 얇은 줄이 생기고, 효과는 입혀지는 프레임에 걸친 **둥근 상자**(종류마다 색, 꺼진 효과는 흐리게)로 보입니다. 이름 칸 = 효과 이름(범위가 있으면 `· 프레임 2–3`)과 켜기 체크 상자(누르면 켜고 끔, 실행취소 1단계). 레이어 이름 칸의 **fx**를 누르면 그 레이어의 효과 줄을 접고 펼칩니다(파일에 저장, 실행취소 없음 — 그룹 접기처럼, 레이어 메뉴 "효과 줄 접기/펼치기"도 같음). 그룹을 접으면 부위의 효과 줄도 함께 접힙니다.
      - **칸을 골라 효과 추가**: 셀(여러 칸이면 끌어서 고름)을 우클릭 → **효과 추가… (프레임 3~5)** → 효과 창이 열리고, **추가 범위**가 고른 칸의 프레임으로 채워져 있습니다. 효과 종류 상자를 두 번 누르거나 목록으로 끌어 놓으면 그 범위에만 입혀지고, 추가 범위("모든 프레임" 체크 또는 시작~끝 프레임)는 창에서 따로 바꿀 수 있습니다(추가한 뒤에도 효과 설정 맨 위에서 바꿈). 추가 범위를 그대로 둔 채 움직이는 효과를 추가하면, **한 칸**만 골랐을 때는 그 프레임부터 그 프레임이 든 태그 끝(태그가 없으면 마지막 프레임)까지로 넓혀 추가합니다("추가 범위"와 움직이는 효과 상자 도움말에 범위가 보임). 레이어 이름 칸 우클릭의 **효과…**로 열면 추가 범위는 모든 프레임입니다.
      - **효과 고르기·지우기·옮기기**: 효과 줄 이름이나 상자를 누르면 그 효과가 골라집니다(이름 칸과 상자 둘레에 파란 테두리, 타임라인 선택 종류 중 하나 — 프레임·레이어·셀 선택과 함께 쓰지 않음). Shift+클릭 = 같은 레이어에서 범위로 더하기, Ctrl/⌘+클릭 = 하나씩 더하고 빼기(다른 레이어 효과도 함께). 체크 상자는 고르지 않고 켜고 끄기만 합니다. **Delete(⌫)** = 고른 효과 모두 삭제("효과 N개 삭제", 실행취소 한 단계). 효과 **이름을 위아래로 끌면** 순서가 바뀌고(이어서 고른 효과는 덩어리째, 끄는 줄이 포인터를 따라오고 다른 줄이 비켜 섬), **다른 레이어의 줄 위에 놓으면 그 레이어로 옮깁니다**(놓을 자리가 파란 선으로 보임, 레이어 본줄 위면 맨 앞). 놓으면 실행취소 한 단계, Esc는 취소. Ctrl/⌘+C·V로 고른 효과를 복사해 현재 레이어 효과 목록 끝에 붙입니다.
      - 상자 **양 끝(손잡이)**을 끌면 그 끝이 프레임 칸에 맞춰 움직이고(최소 1프레임), **몸통**을 끌면 범위를 통째로 옮깁니다(누르면 그 효과가 골라지고 이어서 끌기). 끄는 동안 캔버스·썸네일에 바로 보이고, 놓으면 실행취소 한 단계입니다. 끌어서 모든 프레임을 덮으면 "모든 프레임"이 됩니다(뒤에 프레임을 추가해도 입혀짐). 상자를 두 번 누르면(또는 효과 줄 이름을 두 번) 그 효과를 고른 채 효과 창이 열립니다.
      - **우클릭**(고르지 않은 효과면 먼저 고름, 맨 위에 "효과 N개 선택됨"): 효과 설정…, 모든 프레임으로, 이 프레임만, 이 프레임부터 끝까지, 처음부터 이 프레임까지, 켜기/끄기, 삭제(⌫ — 고른 효과 모두), **효과 영구 적용**, 효과 복사·붙여넣기. 상자 밖 빈 칸이면 **여기까지 늘리기**와 **여기부터 복사본 추가**(같은 설정의 효과를 그 프레임~끝 범위로 하나 더 — 떨어진 구간에 같은 효과를 줄 때)도 있습니다.
      - **효과 영구 적용**(효과 줄 우클릭, 효과 창의 **영구 적용** 단추): 고른 효과(여러 개면 모두)를 셀 픽셀에 구워 넣고(이후 그림처럼 고칠 수 있음) 효과 목록에서 뺍니다. 실행취소 한 단계, 상태 표시줄에 "효과 영구 적용: 외곽선 (프레임 1~4, 셀 4개)". 효과는 위에서부터 차례로 입혀지므로 고른 효과보다 **위의 켜진 효과도 함께** 굽고(메뉴에 "(위 효과 N개 포함)" — 보이던 그대로가 됨), 아래 효과는 효과로 남습니다. **잔상**을 고르면 뒤의 켜진 효과도 함께 구워 과거 프레임의 움직임이 중복되지 않게 합니다. 구운 효과들이 입혀지는 프레임의 저장된 셀마다(움직이는 효과는 그 프레임의 모습으로, 바뀌는 것이 없는 프레임도 그대로 구움) 굽습니다. 일반 레이어는 캔버스 크기로 잘리고, **부위**는 번진 그림(바깥 외곽선·그림자·반사·터지기·늘었다 줄기)이 들어가도록 부위 크기·위치를 넓힙니다(모든 프레임·스킨 셀이 같이 옮겨지고 피벗·테두리는 같은 그림 지점, 자동 배치 그룹이면 다시 배치). 스킨이 있는 부위는 각 스킨 **자신의** 셀에 굽습니다(첫 스킨 셀을 물려받아 보이는 스킨 칸은 첫 스킨 셀이 구워지므로 따로 만들지 않음). **그룹 효과**는 여러 부위를 합친 모양에 입혀지므로 영구 적용할 수 없습니다(메뉴가 꺼지고 "그룹 효과는 영구 적용할 수 없습니다 — 부위에 적용하세요"). 잠긴 레이어도 꺼집니다.
      - **프레임을 바꾸면**: 범위는 태그처럼 **프레임 번호** 기준입니다. 범위 안에 프레임을 넣거나 범위 안 프레임을 복제하면 늘어나고, 범위 앞에 넣으면 뒤로 밀리며, 지우면 줄어듭니다. 범위의 프레임을 모두 지우면 그 효과도 지워집니다(같은 실행취소 단계라 되돌리면 함께 돌아옴). 프레임 순서 바꾸기는 범위를 그대로 둡니다(그 자리로 온 프레임에 입혀짐).
    - **어디에 보이나**: 캔버스·미리보기·재생·프레임 시트·썸네일은 효과를 입힌 합성입니다(번진 부분은 캔버스 밖이면 잘림, 프레임마다 그 프레임이 범위 안인 효과만). 부위를 골라 그리는 **부위 화면**은 고치는 그림 그대로(효과 없이) 보이고, 그룹·프레임 화면에서 효과가 보입니다. **부위 아틀라스**는 부위 자신의 효과만 넣습니다(그룹 효과는 부위들이 겹친 모양에 대한 것이라 프레임 시트에만). 바깥 외곽선·그림자처럼 번지는 효과가 있으면 그 부위 스프라이트를 효과 여백만큼(**프레임 범위와 관계없이** 켜진 효과 기준 — 효과가 없는 프레임도 모든 프레임·스킨 같은 크기) 넓히고, 피벗은 같은 픽셀을, 9-slice 테두리는 같은 선을 가리키도록 옮깁니다(Unity에서 같은 피벗에 놓으면 캔버스와 같은 자리에 보임). 효과가 없거나 모두 꺼져 있으면 결과는 효과 기능이 없던 때와 똑같습니다.
- **미리보기(오른쪽 위)**: 현재 태그(없으면 모든 프레임)를 실시간 재생, 자체 FPS, 배율 단추 하나(클릭하면 맞춤 → 1× → 2× → 4× 차례로, 오른쪽 클릭은 거꾸로), 배경(배율 단추 옆, 닫힌 상자는 색 견본만 / 펼치면 견본 + 이름: 체커·검정·흰색·회색·초록·사용자 색).
- **내보내기 창(Ctrl+E, 파일 > 내보내기…)**: 바꾸는 즉시 적용됩니다(설정 하나마다 실행취소 1단계). 아래 **닫기** 옆 파란 **내보내기**를 누르면 창을 닫고 지금 설정대로 내보냅니다(저장할 때 내보내기가 켜져 있으면 Ctrl+S만으로도 내보냄). 탭은 **내보내기**와 **Import Settings** 두 개입니다. 내보내기 탭은 가로로 넓은 두 칸입니다: **왼쪽 = 설정**(세로 스크롤), **오른쪽 = 결과 미리보기**(세로 스크롤), 가운데 경계를 끌어 폭을 나눕니다. 창 위치·크기(기본 1100×760, 화면보다 크면 줄임, 최소 760×480)·나눈 비율·접어 둔 묶음은 다음에도 그대로입니다. 선택지가 두세 개인 설정은 모서리가 살짝 둥근 네모 칸이 붙은 **세그먼트 토글**(예: `[격자|자동 배치]`, 고른 칸만 채워짐 — 마우스·←/→ 키, 칸마다 도움말 풍선)로, 선택지가 많은 것(파일 형식 등)은 콤보로 보이고, 줄마다 왼쪽 이름표 + 오른쪽 값의 표 모양입니다. 긴 설명은 짧은 글 + ⓘ 도움말 풍선이고, 폭이 좁아도 글은 줄바꿈되어 잘리지 않습니다.
  - **시트 설정은 한 벌**: 프레임 시트와 부위 아틀라스는 **같은 시트 설정**(배치·정렬·칸 수·간격·잘라내기·2의 거듭제곱·따로 파일·칸 이름·스킨)을 같이 씁니다. 한쪽에 없는 축은 건너뜁니다(프레임 시트에는 "부위" 축이 없음, "부위마다 따로 파일"은 부위 아틀라스만). 정말 한쪽에만 있는 것만 결과별로 둡니다 — 프레임 시트: 이름·Single 프레임, 부위 아틀라스: 이름·원래 위치 유지·Sprite Library.
  - **왼쪽 설정 열**(묶음마다 제목을 눌러 접고 펼침, 위에서부터): **공통** — **내보낼 결과** `[프레임 시트|부위 아틀라스|둘 다]`(부위가 있을 때), **스킨** `[지금 착장|고른 스킨]` + **스킨 고르기… (N개)**, **스킨 담기** `[한 이미지|따로 파일]`(고른 스킨일 때), **배치** `[격자|자동 배치]`, **정렬** 목록(줄바꿈 포함, 아래), **칸 수** `[자동|가로 N칸|세로 N칸]`(격자일 때), 최대 가로·넣는 순서(자동 배치일 때), **따로 파일** 태그마다·부위마다 `[끔|켬]`, **칸 이름** `[프레임 번호|태그 기준]`(바꾸면 Unity 참조 경고), **칸 사이 간격**, **테두리 잘라내기**, **2의 거듭제곱** → **파일**(저장할 때 내보내기, 폴더, 파일 형식 PNG/JPG(품질)/TGA/BMP, Unity .meta `[끔|자동|항상]` — 자동 = Unity Assets 안이거나 이미 .meta가 있을 때) → **프레임 시트**(이름, Single 모드면 Single 프레임, 내보낼 경로) → **부위 아틀라스**(이름, 자동 배치면 원래 위치 유지, **Sprite Library** `[끔|켬]`, 경로) → **고급**(**시트별 다르게** `[끔|켬]` — 켜면 부위 아틀라스만 쓰는 시트 설정 한 벌이 따로 생겨 그 아래에 같은 줄들로 보입니다(끄면 공통으로). 예전 파일에서 두 시트 설정이 달라 하나로 합치면 결과가 바뀌는 경우엔 결과를 그대로 두려고 이렇게 "따로"로 옮겨 두고, **공통으로 맞추기** 단추를 보여 줍니다). 설정은 한 곳에만 있습니다.
  - **오른쪽 미리보기 열**: ① 프레임 시트 ② 부위 아틀라스의 **최종 결과**가 파일마다 제목(파일 이름 — 스킨 항목) + 열 폭에 맞춰 크게 그린 시트 + 칸 목록(칸 이름 = Unity `.meta` 스프라이트 이름, 고르면 그 프레임·부위로)으로 쌓입니다(스킨 담기·따로 파일에 따라 여러 개).
  - **프리셋**(탭 줄 오른쪽 끝 단추 — 누르면 작은 창): 지금 내보내기 설정을 이름 붙여 **앱 설정**에 저장해 두고 다른 프로젝트에서도 씁니다 — **지금 설정 저장…**(이름 입력, 같은 이름이면 덮어쓸지 물음), **불러오기**(기본 제공 프리셋 "프레임 시트 기본"·"부위 아틀라스 + Sprite Library"·"스킨마다 따로 파일", 그 아래 내 프리셋 — 고르면 지금 프로젝트에 적용, 실행취소 1단계), **기본 설정으로**(내보내기 설정을 처음 값으로, 파일 이름·폴더는 그대로, 실행취소 1단계), **관리**(이름 바꾸기…·지금 설정으로 덮어쓰기·삭제 — 기본 제공 프리셋은 못 바꿈, **JSON 내보내기…/JSON 가져오기…** — 가져오면 같은 이름은 덮어쓰고 기본 제공 이름과 겹치면 " (가져옴)"을 붙임). 담는 것: 내보낼 결과, 공통 시트 설정 전부(스킨 방식·담기·배치·정렬·줄바꿈·칸 수·간격·잘라내기·2의 거듭제곱·최대 가로·넣는 순서·따로 파일·칸 이름·물려받은 칸 굽기), 시트별 다르게(부위 아틀라스 설정), Sprite Library, 파일 형식·JPG 품질, .meta 방식, 저장할 때 내보내기. **프로젝트마다 다른 값은 담지 않고 적용해도 그대로 둡니다**: 프레임 시트·부위 아틀라스 이름, 폴더, 고른 스킨·착장, 합성에서 뺀 레이어, Single 프레임, 원래 위치 유지, Import Settings. 파일은 설정 폴더의 `export-presets.json`(`{"version":1,"presets":[…]}`, 기본 제공 프리셋은 쓰지 않음, JSON 내보내기와 같은 형식)입니다.
  - **스킨 고르기** 창(공통 묶음의 단추): **모두 선택/모두 해제**, 그룹(슬롯)마다 스킨 체크(작은 썸네일, 첫 스킨에 "(기본)", 그 아래 부위 전용 스킨은 `<부위> 전용` 제목 아래 들여 쓰고 **개별** 배지), **착장 프리셋** 체크(프레임 시트만), **합성에 넣을 레이어**(최상위 레이어·그룹마다 — 끄면 프레임 시트 합성에서 빠지고 부위 아틀라스에서는 그 그룹 부위가 빠짐), **물려받은 칸도 이 스킨 스프라이트로**(부위 아틀라스). 확인을 누를 때 실행취소 1단계로 적용됩니다.
  - **칸 수**: **자동**(새 프로젝트 기본값)은 시트의 긴 변(가로·세로 중 큰 값, 칸 간격 포함)이 가장 작게, 같으면 넓이(빈 칸)가 가장 작게, 그래도 같으면 가로로 넓게 고릅니다(같은 크기 7칸 → 3×3, 6칸 → 3×2, 세로로 긴 칸 4개 → 한 줄). **가로 N칸** = 한 줄에 N칸씩 줄바꿈, **세로 N칸** = 줄 수가 N 이하가 되는 가장 적은 가로 칸 수(묶음이 N개보다 많으면 줄바꿈 없음).
  - **정렬·줄바꿈**: 칸을 늘어놓는 기준을 위에서부터 **세로 목록**으로 보입니다 — 줄마다 손잡이(점 여섯 개) + 순번(1, 2, 3) + 이름(부위·스킨·프레임) + 위/아래 단추. 손잡이를 **끌어서** 순서를 바꾸고(끄는 줄이 떠서 따라오고 다른 줄이 비켜 섬, 태그 줄은 프레임과 한 덩어리, Esc = 취소), 위/아래 단추나 줄을 고른 뒤 **Alt+↑/↓**로도 옮깁니다(바꿀 때마다 실행취소 1단계, 미리보기 바로 갱신). **태그**는 늘 프레임 바로 앞에 붙어 다니는 줄로 `[끔|켬]`만 바꾸고(꺼 두면 흐리게), 결과에 없는 축(프레임 시트만 볼 때의 "부위")은 흐리게 자리만 보입니다. **줄바꿈**은 줄 사이의 **여기서 새 줄** 중 하나를 고르거나(그 위의 기준이 같은 칸끼리 한 줄로 묶어 새 줄에서 시작) 맨 아래 **줄바꿈 없음**(칸 수로만)을 고릅니다. 줄 안의 자리는 나머지 기준으로 정하며 같은 값은 같은 열에 맞춥니다(프레임은 프레임 번호 그대로라 내용 없는 프레임 칸은 비움). 예: **부위 → 스킨 → 프레임, 스킨 아래에서 새 줄**(기본 — Head 기본 줄, Head knight 줄, Body …), **스킨 → 부위 → 프레임, 스킨 아래에서 새 줄**(기본 스킨 전체 다음 knight 전체), **프레임 → 부위 → 스킨, 프레임 아래에서 새 줄**, 태그를 켜면 부위 × 스킨 × 태그마다 한 줄(프레임 시트는 여러 태그에 든 프레임을 태그마다 넣고, 부위 아틀라스는 첫 태그에만). 자동 배치도 "목록 순서대로"면 이 순서로 채웁니다(자동 배치에는 줄바꿈 칸이 없음). 정렬은 위치만 바꾸고 칸 이름·Unity 참조는 그대로입니다.
  - **따로 파일**(조합 가능): 태그마다 `<이름>_<태그>.png`(태그 없는 프레임은 `<이름>_untagged.png`), 부위마다(부위 아틀라스) `<부위 아틀라스 이름>_<부위>.png`, 스킨마다 `…@<스킨>.png` — 예: `<부위 아틀라스>_<부위>_<태그>@<스킨>.png`, 프레임 시트 `<이름>_<태그>@<스킨>.png`. 각각 `.meta`와 함께, 파일 이름에 못 쓰는 문자는 `_`, 같은 이름이면 `_1`…. 칸 이름은 한 장일 때와 같습니다(부위마다 파일이면 "원래 위치 유지"는 쓰지 않음). 프레임 시트는 Single 모드이거나 태그가 없으면 태그마다 나누지 않습니다. 결과 파일 이름이 서로 겹치면(예: 태그 `parts` → `<이름>_parts.png`) 내보내지 않고 알립니다.
  - **칸(스프라이트) 이름 규칙**(두 결과 공통) — Unity `.meta`에 그대로 쓰이고, guid·spriteID·internalID는 파일마다 이 이름으로 이어집니다. **프레임 번호**: 프레임 시트 `<시트 이름>_<프레임 번호>`, 부위 아틀라스 프레임 0 = `Head`, 그다음 `Head_1`, `Head_2` …(예전 부위 아틀라스·가져온 PNG의 기본값). **태그 기준**(새 프로젝트 기본값): 프레임 시트 `<태그>_<태그 안 번호>`(첫 태그, 태그마다 줄·파일이면 그 태그), 부위 아틀라스 `Head_idle_0`, `Head_walk_2` …; 태그 없는 프레임은 프레임 번호 규칙. 프레임 시트는 프레임 이름 재정의가 먼저입니다. 부위 아틀라스의 첫 스킨이 아닌 스킨은 뒤에 `@<스킨>`, 프레임 시트를 "한 이미지에 모두"로 담으면 항목마다 `@<항목>`. 경로 구분자(`/`, `\`)는 `_`로, 제어 문자·앞뒤 공백은 지우고, 한 파일 안에서 겹치면 `_1`, `_2` …를 붙입니다.
  - **Import Settings** 탭(`.meta`를 쓸 때만 보임): Unity Texture Importer 인스펙터와 같은 이름·값으로 `.meta`에 씁니다(프레임 시트·부위 아틀라스 공통, 부위 아틀라스는 항상 Multiple). Texture Type `Sprite (2D and UI)`·Texture Shape `2D`(고정), Sprite Mode(Single/Multiple), Pixels Per Unit, Mesh Type(Full Rect/Tight), Extrude Edges(0~32, Tight일 때), Pivot(Single일 때: Center·Top Left…·Custom, 피벗 도구(K)의 기본 피벗과 같은 값), Generate Physics Shape; Advanced: sRGB (Color Texture), Alpha Source(None/Input Texture Alpha/From Gray Scale), Alpha Is Transparency, Read/Write, Generate Mip Maps; Wrap Mode(Repeat/Clamp/Mirror/Mirror Once), Filter Mode(Point (no filter)/Bilinear/Trilinear), Aniso Level(0~16); Default 플랫폼: Max Size(Auto (fit) = 이미지가 들어가는 가장 작은 2의 거듭제곱, 32~16384), Resize Algorithm(Mitchell/Bilinear), Format(Automatic/RGBA 32 bit/RGB 24 bit), Compression(None/Low/Normal/High Quality), Use Crunch Compression, Compressor Quality(0~100). 기본값은 픽셀 아트용(Point, 압축 없음, 밉맵 끔, Clamp).
- **GIF 애니메이션으로 내보내기(파일 > GIF 애니메이션으로 내보내기…)**: 애니메이션을 공유용 GIF(GIF89a) 한 파일로 씁니다. 프로젝트는 바꾸지 않습니다. 고르는 것은 **범위**(현재 태그 — 현재 프레임이 태그 안에 있으면 기본값 / 모든 프레임 / 태그 고르기, 태그의 역방향·왕복은 그대로), **배율** 1~10×(최근접, 기본 = 결과가 256px쯤 되는 배율), **반복**(무한 반복 / N번 재생), **배경**(투명 — 알파 50% 미만은 투명, 나머지는 불투명 / 배경색 위에 합성)입니다. 오른쪽 미리보기는 그 배율로 실제 프레임 길이대로 재생되고(칸보다 크면 줄여 보임), 결과 크기·프레임 수·길이·색 수를 보입니다. 그림은 프레임 시트와 똑같이 합성합니다(레이어 효과·지금 착장, 숨긴 레이어·내보내기에서 뺀 레이어 제외). 모든 프레임 색이 255개 이하면 팔레트 하나로 **무손실**, 넘으면 프레임마다 256색 이하로 줄입니다(median cut, 디더링 없음). GIF 지연은 1/100초 단위라 누적 시간을 반올림해 전체 길이를 맞추고, 브라우저가 느리게 바꾸는 0.02초 미만은 0.02초로 씁니다. **내보내기…**를 누르면 저장 위치를 묻고(기본 = 프로젝트 옆 `<프로젝트>.gif`, 태그면 `<프로젝트>_<태그>.gif`), 쓴 뒤에도 창이 열려 있어 용량·크기·길이를 보여 줍니다. 반복·배경 설정은 앱 설정에 기억합니다. 단축키는 환경 설정 > 단축키(`파일/GIF 애니메이션으로 내보내기…`)에서 정할 수 있습니다.
- **도구 설정(오른쪽, 미리보기 아래)**: 제목 줄에 고른 도구 이름(예: `도구 설정 · 연필`)이 보이고, 그 도구의 세부 설정만 나옵니다(길면 스크롤). 도구 설정은 실행취소 대상이 아니며 다음 실행 때도 그대로입니다. 도구별 내용은 아래 [도구](#도구)에 있습니다. 설정이 없는 도구(사각·원·자유 선택 등)는 한 줄 안내만 보입니다.
  - **피벗**(피벗 도구 K일 때): 그리는 대상(부위를 고르면 그 부위, 아니면 프레임·프레임별)의 피벗을 **픽셀 단위**로 보여 줍니다. 위에 **5×5 단추**(가로·세로 0, 1/4, 1/2, 3/4, 끝 — 바깥 8방향은 화살표, 가운데 점), 그 아래 X(왼쪽에서)·Y(아래에서, Unity와 같음) 0.5px 단위 숫자와 최대값(`/ 16 px`). 단추는 정수 픽셀에 맞춥니다(가운데는 내림: 15px → 7px, 1/4 = 16px → 4px, 3/4 = 너비 − 1/4 → 12px, 오른쪽 = 너비, 위 = 높이). "현재 프레임만 따로"로 프레임별 피벗. 피벗 도구로 끄는 동안에도 숫자가 따라갑니다(값 바꾸기는 실행취소 1단계).
- **상태 표시줄**: 커서 좌표 · 색 · 캔버스(부위면 부위) 크기 · 프레임/레이어(이름, 부위 크기) · 확대율 · 저장 상태.

## 파일

- `.gpixel`을 열고 저장합니다(Ctrl+S). 저장하면 설정대로 이미지와 `.meta`(Unity 프로젝트 `Assets` 안이거나 이미 메타가 있으면)를 내보냅니다. 기존 메타의 guid·spriteID는 이름 기준으로 유지됩니다.
- **저장한 내용으로 되돌리기**(도구 막대 맨 아래 단추, 파일 > 저장한 내용으로 되돌리기): 확인한 뒤 저장 안 한 수정과 그 실행취소 기록을 버리고 파일을 다시 엽니다(파일 목록의 빨간 점도 사라짐, 현재 레이어·프레임·확대율·위치는 그대로). 되돌리기 자체는 실행취소할 수 없고, 아래 "실행취소 기록 남기기"가 켜져 있으면 마지막으로 저장할 때까지의 기록은 다시 이어 받습니다. 아직 `.gpixel`이 없는 PNG 가져오기는 그 PNG를 다시 가져옵니다.
- **자동 저장**(기본 켬): 편집이 **3초** 동안 없으면 지금 파일을 Ctrl+S와 같이(내보내기 포함) 묻지 않고 저장하고 상태 표시줄에 `자동 저장됨 (이름.gpixel)`을 보입니다. 편집할 때마다 다시 기다리므로 그리는 중에는 저장하지 않고, 획·끌기·떠 있는 선택·변형·숫자 끌기·AI 차례가 끝날 때까지 미룹니다. 디스크에 `.gpixel`이 이미 있는 파일만 저장합니다(저장한 적 없는 새 프로젝트·아직 `.gpixel`이 없는 PNG 가져오기는 Ctrl+S로 처음 저장한 뒤부터). 실패하면 창을 띄우지 않고 상태 표시줄에만 알립니다. 켜고 끄기와 기다리는 시간(1~600초)은 **환경 설정 > 일반**에서 바꿉니다.
- **파일을 닫아도 실행취소 기록 남기기**(기본 켬): 파일을 닫거나 다른 파일로 바꾸거나 앱을 끝낸 뒤 다시 열어도 실행취소·다시 실행 목록(이름 포함, 예: "실행취소: 연필")이 그대로 이어지고 상태 표시줄에 `실행취소 기록 N단계를 이어 받음`이 붙습니다. 기록은 `.gpixel`이 아니라 앱 설정 폴더(`…/Gpixel/History`, 파일마다 폴더 하나 — 같은 그림 조각은 한 번만 저장)에 따로 두며, **저장한 상태까지만** 남깁니다(저장할 때 쓰고, 저장한 그대로인 파일을 닫거나 바꾸거나 끝낼 때도 씀 — "저장 안 함"으로 버린 수정은 기록에 없음). 실행취소 횟수만큼만 남기고 열 때도 그만큼만 읽습니다(오래된 것부터 버림). 다른 프로그램이 파일을 바꿨으면 열 때 기록을 버리고 `파일이 밖에서 바뀌어 지난 실행취소 기록은 버렸습니다`라고 알립니다. 파일 브라우저에서 이름을 바꾸면 기록도 따라가고, 지우면(앱 휴지통) 기록도 지웁니다(휴지통에서 되살려도 기록은 없음). **저절로 정리**: 앱을 시작할 때와 기록을 쓸 때마다 원래 파일이 없어졌거나(밖에서 옮기거나 지움) 밖에서 바뀌었거나 **보관 기간**(기본 30일) 동안 열거나 저장하지 않은 파일의 기록을 지우고, 전체가 **최대 용량**(기본 500MB)을 넘으면 오래 안 쓴 파일 기록부터 지웁니다.
- **파일 역할**: `.gpixel` = 편집 원본(레이어·레이어 효과·프레임·태그·부위·스킨(그룹마다 스킨 목록·지금 착장·부위별 스킨 재정의·스킨 셀)·착장 프리셋·내보내기 설정 — 편집 정보는 여기에만 저장; 형식 버전 3, 스킨이 없던 예전 파일은 그룹마다 스킨 "기본" 하나로, 효과가 없던 예전 파일은 효과 없이 읽음, 프레임 범위가 없던 효과는 모든 프레임), 내보낸 이미지 = 결과물(Unity·다른 프로그램용), `.meta` = Unity 설정, `.spriteLib` = Unity Sprite Library(켰을 때). 예전 버전이 이미지 옆에 쓰던 `.png.gpixel.json`은 더 이상 만들지 않고, 다시 내보낼 때 지웁니다(남아 있는 것은 PNG를 가져올 때 애니메이션을 살리는 데만 읽음).
- **옛 결과 정리**: `.gpixel`은 마지막으로 내보낸 결과 파일 목록(프로젝트 기준 상대 경로, 이미지·`.spriteLib` + `.meta`)을 함께 저장합니다. 내보내기 방식·이름을 바꿔 결과가 줄거나 이름이 바뀌면(예: 태그마다 따로 파일 → 한 장, 스킨 이름 바꾸기, Sprite Library 끄기), 다음 저장·내보내기 때 **기록에 있고 이번에 만들지 않는, 그 자리에 실제로 있는 파일**(+ 그 파일의 `.meta`)만 **앱 휴지통**으로 보내고 상태 표시줄에 "옛 결과 N개 정리(앱 휴지통)"라고 알립니다(파일 목록에서 Ctrl+Z·앱 휴지통 보기로 되살림; 옮기지 못하면 내보내기는 그대로 두고 알리기만 함). 이름이 같아 계속 쓰는 파일은 덮어써서 guid가 그대로입니다. 기록이 없는 예전 프로젝트는 처음엔 아무것도 지우지 않고 그 내보내기부터 기록하며, 다른 이름으로 저장하거나 밖에서 복사·이름을 바꾼 프로젝트도 원래 프로젝트의 결과물을 건드리지 않습니다(기록에 프로젝트 파일 이름이 함께 있음). 기록에 없는 파일(사용자가 따로 만든 파일)은 절대 건드리지 않습니다. 내보내기 창의 파란 **내보내기**로 기록이 바뀌면 프로젝트가 수정됨으로 표시되고 저장할 때 기록됩니다.
- 파일 브라우저에서 `.gpixel` 이름을 바꾸거나 지울 때, 저장 시 내보내기가 켜져 있고 폴더·이름을 따로 지정하지 않았으면 프로젝트 폴더의 기본 이름 결과물(`<프로젝트>.png`, `<프로젝트>_<태그>.png`, `<프로젝트>@<착장>.png`, `<프로젝트>_parts.png`, `<프로젝트>_parts_<부위>.png`, `<프로젝트>_parts@<스킨>.png`, `<프로젝트>_parts_<그룹>@<스킨>.spriteLib` 등 — 지금 설정으로 만들 파일과 마지막 내보내기 기록에 있는 파일)과 `.meta`(예전 `.png.gpixel.json`이 남아 있으면 그것도)를 함께 이동하거나 앱 휴지통으로 보냅니다(Unity guid 유지, 이름을 바꾸면 기록도 새 이름으로). 내보내기 폴더·이름을 따로 지정한 파일은 건드리지 않으며, 대상 이름에 파일이 있으면 덮어쓰지 않습니다. 파일 목록은 이 결과물들을 프로젝트 하나로 묶어 숨깁니다.
- PNG를 열면 프로젝트로 가져옵니다(같은 이름 `.gpixel`이 있거나 같은 폴더의 `.gpixel`이 그 PNG를 내보내기로 등록했으면 그 프로젝트를 엶). 메타/사이드카에 칸이 있으면 칸 크기가 서로 다를 때 **부위**(그룹 하나 + 칸마다 부위 하나), 모두 같으면 "부위로 / 애니메이션 프레임으로"를 묻습니다(애니메이션이면 칸마다 프레임 하나). 칸 정보가 없는 시트는 **프레임·레이어 > 격자로 나눠 프레임 만들기**로 칸 크기·칸 수·자동(덩어리)으로 나눌 수 있습니다.
- 저장할 때 `.gpixel`은 저장됐는데 PNG/메타 내보내기만 실패하면(다른 프로그램이 파일을 잡고 있는 등) 그렇게 알려 주고, 자기 저장을 "밖에서 바뀜"으로 묻지 않습니다.
- **끝낼 때 한 번에 묻기**: 창을 닫거나 끝내기(업데이트 설치로 끝낼 때도)를 하면, 저장하지 않은 변경이 있는 파일(지금 파일 + 메모리에 남겨 둔 파일)을 **한 창**에 모아 보여 줍니다 — 파일마다 체크 상자(기본 켬)·썸네일·이름·폴더(가져온 PNG면 "저장하면 `<이름>.gpixel`을 만듭니다"). **선택한 파일 저장**은 체크한 파일을 Ctrl+S와 같이(.gpixel + 내보내기) 화면을 바꾸지 않고 저장한 뒤 끝내고(저장 위치가 없는 새 프로젝트는 저장 위치를 물음), 하나라도 저장하지 못하면 알리고 끝내지 않습니다. **저장 안 함**은 저장하지 않고 끝내고, **취소**는 끝내지 않습니다.
- 내보낼 칸 이름: 타임라인 프레임 우클릭 > "내보낼 칸 이름…"(비우면 `{태그}_{번호}` / `{파일}_{번호}`). 전체 규칙은 위 내보내기 창의 "칸(스프라이트) 이름 규칙".
- 설정은 Windows `%AppData%\Gpixel\settings.json`, macOS `~/Library/Application Support/Gpixel/settings.json`, Linux `~/.config/Gpixel/settings.json`(최근 폴더/파일, 창 배치, 확대율, 격자·타일 설정, 팔레트 목록, 색 고르기 방식, 도구 옵션, 미리보기 설정). 내보내기 설정 프리셋은 같은 폴더의 `export-presets.json`.
- **오류 로그**: 예상하지 못한 오류가 생기면 앱을 끝내지 않고 "예상하지 못한 오류가 생겼습니다 — 작업은 계속할 수 있습니다" 창을 띄우고, 내용(시각·버전·OS·창·예외와 호출 스택)을 설정 폴더의 `Gpixel/Logs/crash-YYYYMMDD-HHmmss.log`에 남깁니다(최근 20개). **도움말 > 오류 로그 폴더 열기**로 열 수 있고, 버그를 알릴 때 이 파일을 붙여 주세요. 앱이 끝날 수밖에 없는 오류면 수정된 문서를 `Gpixel/Recovery/`에 따로 저장해 둡니다. 환경 변수 `GPIXEL_DATA_DIR`을 주면 설정·로그 등 설정 폴더 전체를 그 폴더로 바꿉니다(시험용).
- **환경 설정**(편집 > 환경 설정…, Ctrl/⌘+,):
  - **일반**: 실행취소 횟수(기본 1000, 최대 10000 — 줄이면 열린 프로젝트의 오래된 기록부터 버림), **실행취소 기록**(파일을 닫아도 실행취소 기록 남기기 — 기본 켬, 보관 기간 N일(0 = 제한 없음, 기본 30일)·최대 용량 N MB(기본 500MB), 지금 쓰는 용량·파일 수와 **기록 모두 지우기**; 끄면 새로 쓰지도 읽지도 않고, 남은 기록을 지울지 묻습니다 — "아니요"면 그대로 두고 보관 기간·용량대로 저절로 정리), **자동 저장**(기본 켬, N초 동안 편집이 없으면 저장 — 기본 3초, 1~600초; 끄면 기다리던 자동 저장도 바로 멈추고, 바꾼 시간은 다음 편집부터), 앱 휴지통 보관(기간 제한 N일·용량 제한 N GB, 각각 끌 수 있음 — 기본: 기간 제한 없음, 용량 1GB).
  - **단축키**: 메뉴 명령·도구·도구 옵션과 메뉴 없는 키(선택 내려놓기 Enter, 캔버스 Esc, 방향키로 1/8px 옮기기, 이전 프레임 보기 H, 선택 칸 M 등) 전부를 바꿉니다. 줄마다 **바꾸기**(누른 키로 바꿈)·**추가**(키 하나 더)·**없음**·**기본값**, 검색(명령·분류·키), **모두 기본값**. 다른 명령이 쓰는 키를 지정하면 그 명령에서 빼도 되는지 묻습니다. **내보내기(JSON)…**는 모든 명령의 지금 단축키를 `{"version":1,"shortcuts":{"편집/실행취소":["Ctrl+Z"], …}}`로 쓰고, **불러오기(JSON)…**는 파일에 있는 명령만 바꿉니다(모르는 명령·읽을 수 없는 키는 건너뛰고 알림, 겹치는 키도 알림). 표기의 `Ctrl`은 명령 키(Windows Ctrl, macOS ⌘)라 같은 파일을 두 OS에서 씁니다. 바꾼 키는 메뉴·도구 막대 도움말·위 막대 도구 이름에 바로 보이고, 기본값과 다른 명령만 `settings.json`의 `Shortcuts`에 저장됩니다(F1 단축키 목록은 기본값).

## 부위(그룹) 레이어 · 스킨

캐릭터의 머리·몸·팔·다리처럼 크기가 서로 다른 부위를 프레임마다 그리고, 한 프레임 안에 배치해 애니메이션으로 쓰면서 부위별 스프라이트로도 내보냅니다. 그룹은 **스킨 슬롯**이라 같은 부위 구성으로 체형·의상·장비를 여러 벌(스킨) 그려 바꿔 낄 수 있습니다. 타임라인의 가로축은 항상 프레임입니다.

- **그룹과 부위**: 그룹 레이어("합친 레이어") 아래에 부위 레이어가 들어갑니다. 부위마다 **자기 캔버스 크기**(예: Head 8×5)와 **프레임마다 자기 그림**이 있고, 프레임 캔버스 안의 **위치(오프셋)는 모든 프레임에 공통**입니다.
- **만들기**: 새 프로젝트(Ctrl+N)에서 "부위로 시작(그룹 + 첫 부위)"을 고르면 첫 부위 이름·크기를 정해 시작합니다. 나중에는 **프레임·레이어 > 새 그룹**(Ctrl+Shift+N), **새 부위…**(Shift+P — 현재 그룹에 추가, 그룹이 없으면 먼저 만듦), 타임라인 레이어 이름 우클릭 "새 그룹·새 부위…"나 그룹 우클릭 "부위 추가…"로 만듭니다.
- **타임라인**: 그룹 행은 삼각형으로 접고 펼치며(파일에 저장, 실행취소 대상 아님) 칸에 그룹 합성 썸네일이 보입니다. 부위 행은 들여쓰기되어 이름과 크기(8×5)를 보여 줍니다. 레이어 이름 칸은 270px(긴 이름도 덜 잘림)이고, 그룹 행에는 지금 스킨 **칩**(스킨이 하나여도 "기본"), 부위 행에는 그 부위가 지금 입은 스킨 칩(부위만 따로 고른 스킨이면 강조, 그룹을 따르면 흐리게)이 이름 뒤에 붙습니다 — 칩을 누르면 그 그룹·부위에 맞춰 **스킨 관리** 창이 열립니다. 그룹을 숨기거나 잠그면 부위도 함께 숨김·잠금. 부위는 자기 그룹 안에서만 순서를 바꾸고, 그룹은 부위와 함께 통째로 움직입니다. 병합은 일반 레이어끼리만 됩니다. 접고 펼치기와 행(레이어)·열(프레임) 추가·삭제(실행취소·다시 실행 포함)는 부드럽게 자라고 줄어드는 애니메이션으로 보입니다(다른 파일을 열 때는 바로).
- **배치(그룹 선택)**: 그룹을 고르면 캔버스에 프레임 합성이 보이고, 어떤 도구든 부위 위에 올리면 점선 테두리와 이름이 표시됩니다. 부위마다의 피벗(부위 아틀라스용)은 파란 점 표시로 보입니다(프레임 피벗은 주황, 피벗 표시를 끄면 함께 숨김). 끌어서 옮기고 놓으면 위치가 정해집니다(실행취소 1단계, 모든 프레임에 적용). 부위를 클릭하면 **고른 부위**(파란 실선 + 이름·위치)가 되고 빈 곳 클릭이나 Esc로 풀립니다. 화살표/Shift+화살표는 고른 부위를 1/8px 옮깁니다(고른 부위가 없으면 안내만). 부위를 더블클릭하면 그 부위 레이어를 고릅니다.
- **그리기(부위 선택)**: 부위를 고르면 그 부위만 자기 크기로 보이고 나머지 프레임은 흐리게 둘레에 보입니다. 좌표는 부위 안 기준입니다. 부위 크기는 **프레임·레이어 > 부위 크기…** 또는 부위 우클릭 "크기…"(기준점 9방향, 그린 픽셀은 캔버스 위 같은 자리에 남음), 위치는 우클릭 "위치…"로 숫자를 넣어 바꿉니다. 피벗 도구(K)와 9-slice 도구(S)는 고른 부위 대상입니다.
- **자동 배치(그룹)**: 그룹 우클릭 **자동 배치…**(타임라인 그룹 메뉴)로 작은 창을 열어 부위들을 크기(테두리 상자)대로 늘어놓습니다 — **방향** `[가로|세로|격자]`(격자는 열 수, 열 폭·줄 높이 = 그 열·줄에서 가장 큰 부위), **맞춤**(가로 줄이면 위·가운데·아래, 세로 줄이면 왼쪽·가운데·오른쪽, 격자면 칸 안), **배치** `[앞|가운데|끝|고르게]`(고르게 = 양 끝에 붙이고 사이를 같게), **간격**·**여백**(px), **순서** `[위 부위부터|아래 부위부터]`, **영역**(기본 캔버스 전체, 풀면 X·Y·W·H), **숨긴 부위도 자리 차지**(기본 켬 — 보이기를 바꿔도 다른 부위가 안 움직임). 창 아래 미리 보기에 지금 프레임 부위 그림이 순서 번호와 함께 놓여 보이고, **적용**하면 실행취소 한 단계입니다(Ctrl+Z = 원래 위치). 켜 둔 그룹은 부위를 더하거나 지우거나 순서·크기·캔버스 크기를 바꿀 때마다 **같은 실행취소 단계 안에서** 다시 배치되고(피벗은 그대로, 캔버스 밖으로 넘쳐도 자르지 않음), 타임라인 그룹 행 스킨 칩 왼쪽에 강조색 **마름모**가 보입니다(누르면 설정, 그룹 메뉴는 체크 표시된 **자동 배치 설정…**·**자동 배치 끄기** — 끄면 부위는 지금 자리에 그대로). 부위를 손으로 옮기려 하면(그룹 화면 끌기·방향키, 부위 우클릭 "위치…") "이 그룹은 자동 배치 중입니다. 자동 배치를 풀고 옮길까요?"를 묻고, 확인하면 자동 배치를 끄고 옮깁니다(방향키·위치…는 끄기 + 옮기기가 한 단계, 끌기는 누를 때 한 번 묻고 끈 뒤 다시 끌어 옮김), 취소하면 그대로입니다. AI 도구는 자동 배치 중인 부위를 x/y로 옮기지 못하고 오류로 알립니다(크기 바꾸기는 됨). 설정은 `.gpixel`에 저장됩니다(없던 예전 파일 = 끔).
- **내보내기(둘 다, 각각 켜고 끔)**: 저장하면 ① **프레임 시트**(프레임마다 합성한 애니메이션 시트)와 ② **부위 아틀라스**(부위 × 내용 있는 프레임마다 칸 하나, 항상 Multiple)를 각각 이미지 + `.meta`로 내보냅니다. 배치·정렬·칸 수·따로 파일·칸 이름은 위 [내보내기 창](#화면-aseprite식-배치)의 공통 시트 설정을 따르고, 부위 아틀라스 이름을 비우면 `<프레임 시트 이름>_parts`. guid·spriteID·internalID는 파일마다 이름 기준으로 유지되고, 방식을 바꿔 더 이상 만들지 않는 옛 파일은 앱 휴지통으로 정리됩니다(위 [파일](#파일)의 "옛 결과 정리").
- **스킨(교체형) · 슬롯(겹치기형)**: 그룹마다 이름 붙은 **스킨** 목록이 있고(적어도 하나, 새 그룹·예전 파일은 "기본" 하나) 그중 하나만 보입니다. 같은 그룹의 스킨끼리는 **서로 바뀌고**(교체형), 다른 그룹끼리는 레이어 순서대로 **겹칩니다**(겹치기형) — 예: 맨 아래 "기본 체형" 그룹(스킨: 기본·근육·좀비), 그 위 "헤어"·"갑옷" 그룹(첫 스킨 "없음"을 비워 두고 다른 스킨에 장비를 그림). 슬롯 이름·순서는 정해져 있지 않고 그룹·스킨을 마음대로 더하고 지우고 이름을 바꾸고 순서를 바꿉니다. 그룹을 숨기면(눈) 그 슬롯 전체가 숨겨집니다.
  - **스킨마다 다른 것은 셀(그림)뿐**: 부위 목록·크기·위치·피벗·9-slice는 모든 스킨이 같이 씁니다. 첫 스킨이 아닌 스킨의 **빈 셀은 첫 스킨 셀을 물려받아** 보이므로, 다른 체형은 달라지는 부위만 다시 그리면 됩니다. 장비 슬롯은 첫 스킨을 비워 두면 물려받아도 아무것도 안 보입니다.
  - **부위마다 따로 고르기**: 한 그룹 안에서도 부위 하나만 다른 스킨을 입힐 수 있습니다(예: 몸은 "기본", 머리만 "knight"). 보이는 스킨은 **부위 재정의 → 그룹의 지금 스킨 → (그 셀이 비면) 첫 스킨** 순서이고, 그룹 스킨을 바꾸면 재정의하지 않은 부위만 따라갑니다. 모자·옷·신발을 늘 따로 바꿀 거라면 그룹(슬롯)을 나누는 편이 Unity로 가져가기에도 깔끔합니다(Sprite Library가 슬롯마다 따로 바뀜). 부위 재정의는 그룹 착장과 같은 보기 상태라 실행취소 기록에 남지 않고 파일에 저장됩니다(예전 파일은 재정의 없음). 지운 스킨을 가리키던 부위는 그룹을 따르고, 스킨 삭제를 실행취소하면 돌아옵니다. 내보내기에서 스킨이 "지금 착장"이면 부위마다 지금 보이는(재정의한) 스킨을, "고른 스킨"이면 재정의와 관계없이 체크한 스킨을 내보냅니다.
  - **편집·재생**: 캔버스·재생·미리보기·프레임 시트·합성(복사·병합 등)은 부위마다 **지금 보이는 스킨**을 씁니다. 빌려 보이는(물려받은) 셀에 그리기 시작하면 보이던 첫 스킨 그림을 복사해 그 스킨 자신의 셀로 만들고(그은 것이 없으면 그대로 빌림), 셀 지우기·잘라내기를 하면 다시 빌립니다. 타임라인에서 빌린 셀은 **흐리게** 보이고, 정보 줄·캔버스 안내에 `스킨: knight (Head는 기본에서 빌림)`처럼 나옵니다(부위만 따로 고른 중이면 `· 부위만 따로`).
  - **스킨 관리 창**(타임라인 이름 칸 오른쪽 끝의 **스킨 칩** 클릭 — 그룹·부위 칩이 같은 열에 있고 부위 크기 글자는 칩 왼쪽, **프레임·레이어 > 스킨 관리…**, 미리보기 아래 착장 줄의 **관리…**): 편집하면서 옆에 띄워 두는 창(하나만, 다시 열면 앞으로, 처음 크기 1156×1224 — 화면보다 크면 화면 안으로 줄임)입니다. 맨 위에 **전체 착장**(지금 프레임 합성), 그 아래 그룹(슬롯)마다 한 줄씩 스킨 **카드**(그 스킨을 입힌 그룹 합성 썸네일 — 빌린 칸 포함 — 와 이름, 첫 스킨에 "(기본)", 지금 스킨은 강조)가 나열됩니다. 카드를 **누르면 바로 적용**되어 캔버스·미리보기·타임라인이 바뀝니다. 줄 끝 **새 스킨**·**복제**(지금 스킨), 카드 우클릭 — 적용·복제·이름 바꾸기…(그룹 안에서 겹치지 않게)·삭제(마지막 하나는 못 지움)·앞으로/뒤로·모든 부위를 그룹 스킨으로. **부위별**을 펼치면 부위마다 맨 앞 **없음** 카드(회색 금지 표시 — 부위만 따로 입힌 스킨 없음, 그룹 스킨을 그대로 보임)와 스킨 카드(그 부위의 그 스킨 그림, 첫 스킨에서 빌려 보이면 "빌림" 표시)가 나오고, 스킨 카드를 누르면 그 부위만 그 스킨이 됩니다. 그룹 상자 안의 카드 줄과 부위 줄은 모두 한 줄씩(줄바꿈 없이) 놓여 **한 가로 스크롤로 함께** 움직이고, 카드 사이 빈 곳(부위 이름 등)을 잡고 **좌우로 끌면 상자 안이 통째로** 옮겨집니다(카드를 다시 그려도 보던 자리 그대로). 재정의한 부위가 있으면 그룹 줄에 **모든 부위를 그룹 스킨으로** 단추가 나옵니다. 지금 프레임·편집·실행취소에 맞춰 자동으로 다시 그립니다.
  - **그 밖의 착장 바꾸기**: 미리보기 아래 **착장** 줄(그룹마다 스킨 콤보, 부위를 따로 고른 그룹은 이름 뒤 `*`, 그룹이 없으면 숨김), **프레임·레이어 > 이전/다음 스킨(현재 그룹)**(Alt+[ / Alt+]), 그룹 우클릭 "스킨" 메뉴·부위 우클릭 "이 부위 스킨" 메뉴(없음(그룹 스킨 그대로) + 스킨 목록), 내보내기 창 부위 아틀라스 칸 고르기(그 부위를 따로 고른 중이면 그 부위만, 아니면 그룹 착장을 바꿈). 착장 바꾸기는 보기 전환이라 **실행취소 기록에 남지 않지만** 파일에 저장되고 프레임 시트 결과가 바뀌므로 수정됨 표시가 켜집니다(실행취소해도 지금 착장은 그대로, 스킨을 더하거나 지운 단계를 되돌릴 때만 그때의 스킨으로).
  - **스킨 만들기·고치기**(스킨 관리 창 또는 그룹 우클릭 "스킨" 메뉴): **새 스킨(빈)**, **복제**(첫 스킨을 복제하면 모든 셀 사본, 다른 스킨이면 그 스킨이 직접 그린 셀만), **이름 바꾸기…**, **삭제**, **앞으로/뒤로**(스킨 관리 창에서는 그룹 스킨 카드를 **끌어서** 순서를 바꿀 수도 있습니다 — 끄는 카드가 따라오고 다른 카드가 비켜 서며, 맨 앞으로 놓으면 그 스킨이 기본 스킨, 실행취소 1단계; 카드는 끌지 않고 눌렀다 떼면 입힘, **두 번 누르면 입히고 창 닫기** — 창 아래 **확인**(Enter·Esc)으로도 닫음). 모두 실행취소됩니다. 첫 스킨이 바뀌면(앞으로 옮기거나 첫 스킨을 지우면) 새 첫 스킨이 빌려줄 기본이 됩니다. 그룹을 복제하면 스킨·스킨 셀·부위 재정의까지 복제됩니다.
  - **부위 전용 스킨(개별 스킨)**: 그룹 전체가 아니라 **부위 하나에만 있는 스킨**도 만들 수 있습니다(예: 기본 체형의 Head에만 "모자"). 스킨 관리 창의 부위 줄 끝 **이 부위 스킨**(빈 스킨, 또는 지금 보이는 스킨 복제)이나 타임라인 부위 우클릭 "이 부위 스킨" 메뉴의 **이 부위 스킨…**으로 만들고, 만들면 그 부위에 바로 입혀집니다(부위 재정의). 그 부위의 줄·메뉴에만 나오고(카드에 **개별** 배지, 메뉴에는 "(개별)"), 그룹 스킨 목록·그룹 착장 바꾸기(Alt+[ / Alt+])·다른 부위에는 나오지 않으며, 그 부위의 재정의로만 입습니다. 빈 칸은 전체 스킨과 같은 규칙으로 **그룹의 첫 스킨 셀을 빌리고**, 첫 스킨에도 없으면 비어 보입니다. 이름은 그룹 안에서(전체 스킨과 부위 전용 스킨 모두) 겹치지 않습니다. 카드 우클릭: 적용·복제(같은 부위 전용)·이름 바꾸기…·삭제·앞으로/뒤로(같은 부위 전용 스킨끼리)·**전체 스킨으로 올리기**(다른 부위도 고를 수 있게 — 그 부위들은 빈 칸이라 첫 스킨을 빌림). 부위 줄의 전체 스킨 카드 우클릭 **이 부위 전용으로 내리기**는 다른 부위의 그 스킨 셀을 지웁니다(확인을 묻고, 첫 스킨·마지막 전체 스킨은 내릴 수 없음). 모두 실행취소되고 `.gpixel`에 저장됩니다(예전 파일은 부위 전용 스킨 없음). 부위를 복제하면 그 부위 전용 스킨도 새 부위 전용으로 복제되고(이름 뒤 " 복사"), 부위를 지우면 함께 지워집니다. 착장 프리셋은 부위 재정의로 부위 전용 스킨도 기억합니다. 스킨 관리 창 맨 위 **[전체 | 그룹 스킨 | 개별 스킨]** 토글로 보이는 카드를 거를 수 있습니다(개별 스킨이면 부위 전용 스킨이 있는 부위 줄만 펼쳐 보임).
  - **착장 프리셋**: 지금 착장(그룹마다 스킨 + 부위별 재정의)을 이름 붙여 저장해 두고(스킨 관리 창 **지금 착장 저장…**, 카드 썸네일 = 그 착장을 입힌 지금 프레임), 카드를 누르면 바로 그 착장으로 바뀝니다. 카드 우클릭 — 적용·지금 착장으로 덮어쓰기·이름 바꾸기…·삭제·앞으로/뒤로. 착장은 그룹·부위·스킨을 이름이 아니라 그 자체로 기억하므로 이름을 바꿔도 따라가고, 지운 그룹·부위·스킨 항목은 건너뛰며 적용할 때 무엇을 건너뛰었는지 알려 줍니다(카드에 경고 표시; 지운 것을 실행취소로 되살리면 다시 쓰임). 저장한 뒤에 만든 그룹은 적용해도 그대로 둡니다. 착장 목록 편집(저장·덮어쓰기·이름·삭제·순서)은 실행취소되고, 적용은 착장 바꾸기와 같이 보기 전환(기록 없음)입니다. `.gpixel`에 저장되며 예전 파일은 착장 없음.
- **스킨 내보내기**(공통 설정의 **스킨**):
  - **지금 착장**(기본): 프레임 시트는 지금 착장으로 합성한 한 벌, 부위 아틀라스·Sprite Library는 부위마다 지금 보이는 스킨만(빌려 보이는 칸은 첫 스킨 스프라이트).
  - **고른 스킨**: **스킨 고르기** 창에서 체크한 스킨(기본 = 부위가 있는 그룹의 모든 스킨)과 착장 프리셋. 프레임 시트는 항목마다 합성 한 벌 — 그룹 G의 스킨 S 항목 = G만 S(부위 재정의 무시), 나머지 그룹은 지금 착장; 착장 프리셋 항목 = 그 착장. **스킨 담기**가 **한 이미지**면 모든 항목을 한 시트에(정렬 기준의 "스킨" = 항목 순서, 기본은 항목마다 새 줄) 칸 이름 `<이름>@<스킨>`(착장은 `@<착장>`), **따로 파일**이면 항목마다 `<시트>@<스킨>.png`(칸 이름은 파일마다 같아 Unity 애니메이션을 파일끼리 바꿔 씀). 첫 번째로 고른 첫 스킨(기본) 항목은 `@` 없이 원래 이름이고, 여러 그룹에 같은 스킨 이름이 있으면 `@<그룹>.<스킨>`으로 겹치지 않게 합니다. Single 모드는 항목마다 따로 파일입니다.
  - **부위 아틀라스**: 첫 스킨은 스킨이 없던 때와 **같은 이름**(`Head`, `Head_1` … 또는 `Head_idle_0` …, 그래서 Unity 참조가 그대로), 다른 스킨은 그 스킨이 **직접 그린 셀만** `<이름>@<스킨>`(`Head@knight`, `Head_1@knight`)으로 들어가고 물려받는 셀은 스프라이트를 따로 만들지 않습니다(Sprite Library가 첫 스킨 스프라이트를 가리킴). 첫 스킨을 꺼도 남은 스킨이 **물려받아 보이는 칸의 첫 스킨 스프라이트는 남깁니다**(이름도 그대로). **물려받은 칸도 이 스킨 스프라이트로**(스킨 고르기 창, 기본 꺼짐)를 켜면 물려받는 칸도 그 스킨 이름 스프라이트로 구워 넣어 스킨마다 첫 스킨 없이도 완결됩니다(같은 그림이 스킨마다 한 벌씩 더 생김, 꺼 둔 첫 스킨 스프라이트는 남기지 않음).
  - **부위 전용 스킨 내보내기**: 스킨 고르기 창에서 그 그룹 아래 주인 부위 이름과 **개별** 표시로 따로 체크합니다. 프레임 시트 항목 = 그 부위만 그 스킨(나머지는 지금 착장), 이름 `@<스킨>`; 부위 아틀라스 = 주인 부위만 `<이름>@<스킨>`(`Head@모자`, 빌리는 칸 규칙도 같음); 따로 파일 규칙도 전체 스킨과 같습니다(`…@<스킨>.png`).
  - **예전 설정 이행**: 예전 파일의 프레임 시트·부위 아틀라스 설정은 열 때 공통 설정 한 벌로 합칩니다. 부위 아틀라스 결과가 공통(예전 프레임 시트) 설정으로도 같거나 한쪽 결과를 내보내지 않으면 하나로, 다르면(예: 예전 부위 아틀라스 자동 배치 + 프레임 시트 격자) 부위 아틀라스를 **시트별 다르게**로 그대로 두어 결과가 조용히 바뀌지 않습니다. 예전 "지금 착장 + 착장 프리셋" 프레임 시트 설정은 "고른 스킨(착장만) + 따로 파일"로 옮기고, 지금 착장 파일(이름 그대로)은 더 만들지 않는다고 열 때 알립니다.
- **Sprite Library(.spriteLib)**: 내보내기 탭 부위 아틀라스 묶음의 **Sprite Library** `[끔|켬]`을 켜면 부위 아틀라스 옆에 Unity 2D Animation 패키지(com.unity.2d.animation)의 **Sprite Library Asset**을 **그룹 × 내보낼 스킨마다** `<부위 아틀라스 이름>_<그룹>@<스킨>.spriteLib`(+ `.meta`, guid는 처음 만들 때 정하고 계속 유지)으로 씁니다.
  - **Category = 부위**(그룹의 위 부위부터, 어느 스킨에든 그림이 있는 부위), **Label = 프레임**(칸 이름 규칙의 프레임 부분: 프레임 번호 `0`, `1` … 또는 태그 기준 `idle_0`, `walk_2` …), 스프라이트 = 그 스킨이 직접 그린 스프라이트 → 없으면 첫 스킨 스프라이트(물려받기) → 그것도 없으면 빈 항목(그 프레임엔 아무것도 안 그림, 예: 장비 "없음"). 스프라이트는 부위 아틀라스 `.meta`의 guid·internalID로 가리키므로 Sprite Library를 쓰면 부위 아틀라스 `.meta`는 항상 씁니다.
  - **왜 스킨마다 파일인가**: Sprite Resolver 키프레임은 Category와 Label을 한 값(`m_SpriteHash`)으로 함께 기록하므로, 한 라이브러리에 Label = 스킨으로 넣으면 애니메이션이 스킨까지 고정합니다. 그래서 Unity 예제(Animated Swap·Full Skin Swap)처럼 **같은 그룹의 라이브러리는 Category·Label이 모두 같고 스프라이트만 다르게** 만듭니다. Unity에서는 그룹(슬롯)마다 부위 GameObject들의 부모에 **Sprite Library** 컴포넌트를 두고 그 그룹 라이브러리 하나를 넣은 뒤, 부위마다 **Sprite Resolver**(Category = 부위)로 Label(프레임)을 키프레임합니다. 스킨을 바꿀 때는 그 그룹 Sprite Library 컴포넌트의 에셋만 다른 스킨 라이브러리로 바꾸면 애니메이션은 그대로 씁니다(슬롯마다 따로 바꿀 수 있음).
  - **부위 전용 스킨의 라이브러리**: 부위 전용 스킨도 같은 규칙으로 `<부위 아틀라스 이름>_<그룹>@<스킨>.spriteLib` 하나를 씁니다 — Category·Label은 그 그룹의 다른 라이브러리와 똑같고, 주인 부위 Category만 그 스킨 스프라이트, 나머지 부위는 첫 스킨 스프라이트입니다("기본 + 모자" 라이브러리). 한 라이브러리에 Label을 더 넣는 방식은 Sprite Resolver 키프레임(Category + Label 한 값)이 그 Label에 고정되어 애니메이션을 스킨마다 따로 만들어야 하므로 쓰지 않았습니다. 체형 스킨과 부위 전용 스킨을 함께 입히려면 그 부위 GameObject에 Sprite Library 컴포넌트를 하나 더 두고(가장 가까운 부모의 Sprite Library가 쓰임) 부위 전용 라이브러리를 넣으면 그 부위만 바뀝니다.
- **예전 아틀라스 파일**: 예전 버전에서 만든 아틀라스 `.gpixel`을 열면 그룹 "부위" + 스프라이트마다 부위 하나로 바뀝니다(크기·피벗·9-slice·원래 위치 그대로). 부위 아틀라스 이름이 예전 아틀라스 PNG 이름으로 정해지므로 다시 저장해도 Unity의 guid·spriteID가 그대로 이어집니다(프레임 시트는 새 이름으로 따로 나옴). 여러 레이어였던 스프라이트는 한 장으로 합쳐지고 열 때 알려 줍니다.
- **PNG 가져오기**: 칸 크기가 서로 다른 시트(메타/사이드카에 칸이 있는)는 그룹 하나(파일 이름) + 칸마다 부위 하나로 가져옵니다. 부위 위치 = 원래 칸 위치, 캔버스 = 시트 크기. 부위 아틀라스 이름이 원래 PNG 이름이라 기존 `.meta`의 guid를 그대로 씁니다. 같은 그림의 사본이 생기지 않도록 프레임 시트는 꺼진 채로 가져옵니다(켜면 `<이름>_frames`).

## AI 채팅 — Claude·Codex (말로 그리기·고치기)

VS Code의 Claude·Codex 확장처럼 편집기 안에서 AI와 대화하며 그림을 만들고 고칩니다. API 키를 넣지 않고, 컴퓨터에 설치된 **Claude Code**(Claude 구독 로그인) 또는 **Codex CLI**(ChatGPT 구독 로그인)를 그대로 씁니다. 창 위쪽 **[Claude | Codex]** 는 **탭**입니다(보던 탭은 설정에 기억). 탭마다 대화·세션·입력란·첨부·모델·로그인 화면·되돌리기 단추가 따로 있고, 탭을 바꿔도 대화가 끊기거나 새로 시작하지 않습니다 — 처음 보는 탭만 CLI·로그인을 확인합니다.

- **뒤에서 계속**: 답을 받는 중에 다른 탭으로 가도 그 차례는 멈추지 않고, 글은 원래 탭에 계속 붙습니다. 도는 동안 탭 이름 뒤에 **점**이 붙습니다. 두 AI가 같은 캔버스를 함께 고치지 않도록 **차례는 한 번에 하나만** 돕니다 — 한 탭이 작업 중이면 다른 탭의 보내기는 "Codex가 작업 중입니다 — 끝난 뒤 보내세요" 같은 줄만 남기고 보내지 않으며(입력한 글은 그대로), 이 단계 되돌리기 단추도 차례가 끝날 때까지 쉽니다.
- **열기**: 메뉴 아래 막대 오른쪽 **AI 채팅** 단추(주황 별 모양 아이콘), 메뉴 **AI > AI 채팅**, 또는 Ctrl+L. 작은 창으로 따로 뜨고 위치·크기를 기억합니다(앱을 닫을 때 열려 있었으면 다음에 다시 엶).
- **처음 한 번**: Gpixel 설치 파일에 Claude Code·Codex CLI는 포함되지 않습니다. AI 채팅에서 CLI가 없으면 **터미널에서 설치하고 로그인**을 누르고 실행할 명령을 확인·승인하세요. 보이는 터미널에서 공식 설치 명령을 실행한 뒤 성공하면 로그인 명령이 이어집니다(브라우저 인증은 직접 완료). Codex에 필요한 npm이 없으면 Windows는 `winget`으로 Node.js LTS를 설치하고, winget이 없거나 설치에 실패하면 Node.js 공식 ZIP을 SHA-256 검증 후 사용자 폴더에 설치합니다. macOS는 Homebrew가 있으면 `brew install node`, 없으면 nvm 공식 설치 스크립트로 Node.js LTS를 설치합니다. Gpixel은 설치·로그인 상태를 확인해 채팅으로 넘어갑니다. 설치가 실패하면 터미널의 오류를 확인하고, 화면에 있는 명령 복사·직접 경로 지정·**다시 확인**을 쓸 수 있습니다. macOS의 ChatGPT 앱에 들어 있는 Codex CLI는 저절로 찾습니다. MCP 서버는 Gpixel에 들어 있으므로 따로 설치할 필요가 없습니다. 로그인이 안 되어 있으면 **Claude로 로그인 / Codex로 로그인**(숨은 `claude auth login` / `codex login`) 또는 **터미널에서 로그인**을 누를 수 있습니다. 위쪽에는 로그인 계정이 보입니다.
- **대화**: Enter 보내기, Shift+Enter 줄바꿈. **이미지…**로 참고 그림을 붙이고 **캔버스 첨부**로 지금 프레임을 보여 줄 수 있습니다. **모델**과 **새 대화**는 위쪽에 있고 보이는 탭에만 적용됩니다(모델은 AI마다 따로 기억). 모델 목록 첫 칸 **기본**에는 실제로 쓰일 모델이 붙어 보입니다 — Claude: Claude Code 설정(`~/.claude/settings.json`의 `model`, 예: "기본 · Opus 4.8 (1M)")이나 한 번 답을 받은 뒤 알게 된 모델, Codex: `~/.codex/config.toml`의 `model`(예: "기본 · GPT-5.6-Sol"). Claude는 Claude Code가 받아 둔 모델 목록(`~/.claude/cache/model-catalog/`)의 주요 모델을 정확한 이름으로 보입니다(예: **Opus 5.5 · 가장 똑똑함 / Sonnet 5.5 · 균형 / Haiku 5.5 · 가장 빠름**, 마우스를 올리면 모델 ID — 목록 파일이 없으면 opus·sonnet·haiku 별칭, 한 번 쓰면 버전까지 보임. 예전에 고른 별칭은 "Opus 5 · opus 별칭"처럼 남음), Codex는 Codex가 받아 둔 모델 목록(`~/.codex/models_cache.json` — 예: GPT-6-Astra, GPT-6.1-Sol, GPT-6-Luna; 마우스를 올리면 설명)입니다. 바꾸면 다음 메시지부터 적용됩니다. 답이 오는 동안 **정지**로 멈춥니다.
- **지금 레이어만**(입력란 아래 **캔버스 첨부** 옆 토글, 두 탭 공통·앱 설정에 기억): 켜고 보내면 **보내는 순간 열린 문서의 현재 레이어**(그룹이면 그 부위들까지)만 AI가 고칩니다 — 그 레이어의 모든 프레임에 그릴 수 있고, 다른 레이어·다른 파일은 **볼 수만** 있으며 프레임·레이어·태그·그룹·부위·스킨·착장·캔버스·팔레트 바꾸기, 새 프로젝트·열기 같은 도구는 거절됩니다(저장은 됨). 채팅에 `편집 범위: "hair" 레이어만`이 보이고, AI도 `get_document`의 `editScope`와 메시지 앞머리로 범위를 압니다. 차례 중에 다른 파일을 열면 그 파일은 고치지 않습니다. 끄면 다음 메시지부터 제한이 없어집니다. **캔버스 첨부**는 작업 대상과 상관없는 참고 그림입니다.
- **진행 표시**: 답이 오는 동안 맨 아래 줄에 지금 하는 일과 시간이 0.5초마다 바뀌어 보입니다 — 응답 기다리는 중 / 생각 중(받은 글자 수) / **도구 호출 작성 중: 도구 이름(받은 글자 수)** / 편집기에서 실행 중: 도구 이름 / 답 쓰는 중, 그리고 그 단계 시간 · 전체 시간. 여러 프레임을 한 번에 그리는 큰 도구 호출은 작성에 1분 넘게 걸릴 수 있는데, 받은 글자 수가 늘고 있으면 일하는 중입니다(숫자가 오래 그대로면 네트워크·서버 대기).
- **편집**: AI는 편집기 안 MCP 서버(127.0.0.1, 이 앱이 띄운 CLI만 쓸 수 있는 토큰)의 도구로 열린 그림을 직접 고칩니다 — 문서 정보·그림 보기·픽셀 읽기, 점/줄 단위 그리기, 선·사각형·원, 채우기, 지우기, 색 바꾸기, 프레임·레이어·태그, 그룹·부위 만들기와 배치, 스킨 목록·추가·착장 바꾸기(`list_skins`(부위 전용 스킨은 `partSkins`)·`add_skin`(`part`를 주면 그 부위 전용 스킨, `copy_shown`이면 지금 보이는 스킨 복제)·`set_skin` — `set_skin`에 `part`를 주면 그 부위만(부위 전용 스킨 이름도 됨), `follow_group`이면 그룹 따름으로; 그리기 도구는 늘 부위의 지금 보이는 스킨에 그림), 착장 프리셋(`list_outfits`·`save_outfit`(실행취소됨)·`apply_outfit`), 캔버스 크기, 팔레트·색, 새 프로젝트, 열기, 저장. 저장은 부탁할 때만 합니다. 새 프로젝트·열기는 지금 문서에 저장 안 된 수정이 있어도 됩니다(파일이 있는 문서는 수정한 채 파일 목록에 남음, 빨간 점). 저장한 적 없는 새 프로젝트에 수정이 있을 때만 바꾸지 않고 사용자에게 저장할지 묻게 합니다.
- **되돌리기**: AI의 답 한 번이 실행취소 **한 단계**입니다(Ctrl+Z로 통째로 되돌림). 답마다 결과 그림과 **이 단계 되돌리기 / 다시 적용** 단추가 붙습니다(뒤에 다른 편집이 있으면 함께 되돌릴지 묻습니다).
- **Codex의 차이**: 메시지마다 `codex exec --json`(이어 가면 `codex exec resume`)을 띄우고, 편집기 MCP 도구만 쓰게 합니다(셸·웹 검색·앱·플러그인 끔, 읽기 전용 샌드박스, MCP 도구는 묻지 않고 허용, 프로젝트 폴더의 AGENTS.md는 읽지 않음). 답 글은 다 쓴 뒤 한꺼번에 보이고 비용 대신 시간만 표시됩니다. Codex가 내는 설정 경고(예: 사용자 config.toml의 옛 설정)는 대화마다 한 번 회색 줄로 보입니다.
- 사용량은 각 구독(Claude / ChatGPT)에서 차감되며 답마다 시간(Claude는 비용도)이 작게 표시됩니다. CLI를 실행 파일로 직접 부르는 방식이라, 이 기능을 넣은 앱을 **다른 사람에게 배포**할 때는 Anthropic·OpenAI의 이용 정책(제3자 앱에서 구독 로그인 사용 제한)을 확인하세요.

## 도구

연필(B) · 지우개(E) · 채우기(G) · 그라데이션(F) · 스포이드(I, Alt+클릭 — 그리기 도구에서 Alt를 누르고 이미지 위에 있으면 커서가 스포이드로 바뀜) · 선(L) · 사각형(R) · 원(O) · 사각 선택(M) · 원 선택(M) · 자유 선택(Q) · 스마트 선택(W) · 이동(V, 선택이 없으면 셀 전체를 밀고 "순환" 옵션 — 다른 도구에서도 캔버스 위에서 **Ctrl(⌘)을 누르는 동안**은 임시 이동 도구: 도구 막대의 이동 단추가 눌리고 커서가 이동 모양이 되며, 떼면 원래 도구로) · 밝게/어둡게(D) · 디더링(T) · 색 바꾸기 브러시(C) · 피벗(K) · 9-slice(S).
왼쪽 버튼 = 기본색, 오른쪽 = 보조색(옵션: 지우개). 선·사각형·원·그라데이션이나 브러시 획을 그리는 중에 반대쪽 버튼을 누르면 그 획이 취소됩니다(기록 없음). Shift+클릭 = 마지막 점에서 직선, Shift로 45°·정사각형·정원. 편집 메뉴에 외곽선 추가, 색 바꾸기, 뒤집기·회전, 캔버스 크기(캔버스 위 모드, 아래 참고).

**도구 묶음**: 비슷한 도구는 도구 막대의 한 칸에 묶여 있습니다 — 채우기(채우기·그라데이션), 도형(선·사각형·원), 선택(사각·원·자유·스마트 선택). 묶음 칸은 오른쪽 아래에 작은 삼각형이 있고 마지막으로 고른 도구를 보입니다. 칸을 **길게 누르거나(0.4초) 오른쪽 클릭**하면 옆에 묶음 도구 목록(아이콘·이름·단축키)이 펼쳐지고, 고른 도구가 그 칸으로 바뀝니다. 그냥 누르면 칸에 보이는 도구를 고릅니다. 단축키나 메뉴로 고른 도구도 그 칸에 보입니다. 칸마다 고른 도구는 앱을 다시 켜면 처음 도구로 돌아갑니다.

**선택 도구**: 모두 같은 선택 영역을 만들어 잘라내기·복사·지우기·뒤집기·회전·이동·외곽선·색 바꾸기(선택 영역 안만)·그리기 제한이 똑같이 됩니다(원·자유·스마트 선택은 사각형이 아닌 모양 그대로, 모양 밖은 건드리지 않음). 선택 도구로 캔버스를 **오른쪽 클릭**하면 선택 해제(옮기던 내용은 내려놓음, Ctrl+D와 같음). **M**은 선택 칸의 도구를 고르고, 이미 선택 도구를 쓰는 중이면 누를 때마다 다음 선택 도구로 바뀝니다(사각 → 원 → 자유 → 스마트).
- **사각 선택 / 원 선택**: 끌어서 선택(Shift: 정사각형 / 정원), 클릭만 하면 선택 해제. 선택 안쪽을 끌면 내용을 옮기고 Enter로 내려놓습니다.
- **자유 선택**: 끌어서 테두리를 그리면 놓을 때 처음 점과 이어 닫고 그 안(그린 선 위 칸 포함)을 선택합니다. 끄는 동안 지금 놓으면 선택될 칸 영역이 **파란 점선**으로 보입니다(끈 자취는 흰·검은 개미 줄). 선택 안쪽을 끌면 옮깁니다.
- **스마트 선택**: 클릭한 곳과 비슷한 색 영역을 선택합니다. 허용 오차·이어진 영역만·대각선·기준(현재 레이어 / 보이는 레이어 전체)은 **채우기와 같은 설정**을 씁니다(도구 설정에 같은 칸이 나옴). 옮기려면 이동(V)이나 방향키를 씁니다.

**변형 모드(Ctrl+T, 편집 메뉴 "변형(회전·크기)…")**: 포토샵의 자유 변형처럼 선택 영역(없으면 현재 셀의 칠한 픽셀 전체)을 캔버스 손잡이로 돌리고 늘리고 옮깁니다. 변형 중에는 테두리가 선택 개미 줄·자유 선택 미리보기(파랑)와 다른 **주황 점선**으로, 손잡이는 주황 네모로 보입니다. 숨김·잠긴 레이어나 그룹 화면에서는 들어가지 않습니다.
- **안쪽 끌기** = 옮기기(1픽셀 단위, 방향키도 1px). **네모 손잡이 8개** = 크기(변 = 한 축, 모서리 = 두 축, 반대쪽 변이 제자리; **Shift** = 비율 유지, **Alt** = 가운데 기준; 반대쪽을 넘겨 끌면 뒤집힘; 크기는 정수 픽셀로 맞춤). **사각형 바로 바깥(약 20px 띠)** = 회전(커서가 둥근 화살표로 바뀜, **Shift** = 15° 단위). **주황 표시**는 회전 중심으로, Ctrl+T를 누르면 처음에 **지금 대상의 피벗 자리**(부위면 부위 피벗, 아니면 프레임/기본 피벗 — 캔버스의 피벗 표시와 같은 곳)에 놓입니다. 끌어서 옮기고(반 픽셀 단위) 더블클릭하면 변형 영역 가운데로 갑니다.
- 도구 설정에 **각도(°)·가로/세로 %(음수 = 뒤집기)·중심 X/Y**가 나오고 손잡이와 함께 움직이며, 숫자로 바꿔도 됩니다. **리샘플링**: **RotSprite**(기본 — Scale2x를 세 번 해 8배로 키운 그림에서 최근접으로 집어 회전한 선이 덜 깨지고, 섞지 않으므로 새 색이 생기지 않음) / **최근접**. 고른 방식은 다음 실행 때도 그대로입니다. 0°·90°·180°·270°(뒤집기·정수 배 확대 포함)는 둘 다 최근접과 같아 무손실이고, 512×512px보다 넓은 영역은 RotSprite도 최근접으로 집습니다.
- 늘 떼어 낸 원본에서 다시 그리므로 여러 번 끌어도 누적되어 뭉개지지 않습니다. **Enter**(또는 **적용**) = 적용(실행취소 한 단계, 결과 모양이 선택으로 남음), **Esc**·**Ctrl+Z**(또는 **취소**) = 변형 전 그대로(떠 있던 선택이었으면 그 상태로). 도구를 바꾸거나 다른 편집 명령·저장·다른 파일 열기·프레임/레이어 바꾸기를 하면 먼저 적용됩니다.

**캔버스 크기 모드(Ctrl+Alt+C, 편집 메뉴 "캔버스 크기…")**: 창 대신 캔버스 위에서 새 캔버스 크기와 그림 자리·크기를 정합니다. 들어가면 떠 있는 선택·변형을 먼저 적용하고, 부위를 골랐어도 **현재 프레임 합성 전체**를 미리보기로 보입니다(적용 전에는 아무것도 바뀌지 않음). 새 캔버스 안은 체커 위에 적용될 모습 그대로, 캔버스 밖으로 잘릴 그림은 흐리게, 그림 자리는 흰 점선으로 보이고, 캔버스 테두리는 변형 모드(주황)와 다른 **하늘색 점선**과 흰 네모 손잡이 8개(모서리·변 가운데), 위에 크기 글(예: `24×24 · 그림 32×32 (133%)`)이 붙습니다. 그리기는 막히고 휠 확대·Space 끌기 화면 이동은 그대로입니다.
- **손잡이 끌기** = 그 캔버스 가장자리만 옮김(1픽셀 단위, 최소 1px): 그림은 제자리라 그쪽 여백이 늘거나 그림이 잘립니다. **Ctrl(⌘)+끌기** = 그림 가장자리도 함께 움직여 여백은 그대로 두고 그림 크기를 바꿈(최근접, 늘 원래 그림에서 다시 집어 누적되지 않음), 모서리를 **Ctrl+Shift**로 끌면 그림 비율 유지. **그림 안쪽 끌기**(방향키도 1px) = 캔버스 안에서 그림 옮기기. 한 번의 모드에서 섞어 써도 됩니다. 손잡이 위에서는 커서가 그 방향 화살표로 바뀝니다.
- 도구 설정에 **캔버스 가로/세로**, **그림 가로/세로**(원래 대비 %), **그림 비율 유지**(기본 켬 — 한쪽을 바꾸면 다른 쪽을 원래 비율로), **그림 위치 X/Y**(새 캔버스 기준), **기준점 9방향**(그림을 지금 캔버스 안 그 자리에 놓음, 맞는 자리면 눌려 보임)이 나오고 손잡이와 함께 움직입니다.
- **Enter**(또는 **확인**) = 적용(실행취소 한 단계, 화면에 맞추고 상태 표시줄에 `캔버스 크기: 24×24 · 그림 32×32`), **Esc**·**Ctrl+Z**(또는 **취소**) = 바꾸지 않고 끝. 도구를 바꾸거나 다른 편집 명령·저장·다른 파일 열기·프레임/레이어 바꾸기를 하면 먼저 적용됩니다. 모든 프레임·레이어에 적용되고, 부위는 위치·크기를 같은 비율로(모든 스킨 셀은 최근접, 9-slice 테두리도 비율대로) 바꾸며, 기본·프레임 피벗은 같은 그림 지점을 가리키도록 옮깁니다(부위 피벗은 그대로).

도구를 고르면 오른쪽 독 **도구 설정**에 그 도구의 설정이 나옵니다.

- **브러시**(연필·지우개·밝게/어둡게·디더링·색 바꾸기 브러시): 모양 **사각 / 원 / 마름모**(원은 픽셀 아트 원: 3 = 십자, 4 = 12칸, 5 = 21칸, 7 = 37칸), 크기 1~32(숫자 칸을 좌우로 끌기, `[`/`]`), 옆에 실제 픽셀 모양 미리보기. 크기 1은 모양과 관계없이 한 점이고, 짝수 크기는 가운데에서 오른쪽·아래로 한 칸 더 넓습니다. 캔버스의 커서 테두리도 브러시 모양을 따라갑니다.
- **연필**: 브러시, 픽셀 퍼펙트(P, 크기 1일 때), 오른쪽 버튼 = 지우개, 대칭. **지우개**: 브러시, 픽셀 퍼펙트, 대칭.
- **선·사각형·원**: 선 두께·펜 모양(= 브러시 모양·크기, 사각형·원은 외곽선에만), 사각형·원은 **채움**(U), 오른쪽 버튼 = 지우개, 대칭.
- **채우기**: **허용 오차** 0~100%(0 = 지금처럼 정확히 같은 색만, 높일수록 비슷한 색도 같은 색으로 채움), **이어진 영역만**(끄면 맞는 색 전체, Shift+G), **대각선으로도 잇기**(8방향), **기준: 현재 레이어 / 보이는 레이어 전체**(보이는 레이어 전체면 합성된 모습으로 영역을 정하고 칠하기는 현재 레이어에), 오른쪽 버튼 = 지우개, 대칭.
  - 허용 오차는 클릭한 점의 색과 비교합니다: R·G·B·A 채널마다의 차이 중 가장 큰 값이 `허용 오차 % × 255` 이하이면 같은 색입니다. 완전 투명(알파 0) 픽셀은 RGB 없이 알파 차이만 잽니다.
- **그라데이션(F)**: 캔버스에서 시작점 → 끝점으로 끌면 그 방향의 선형 그라데이션을 현재 셀에 칠합니다(끄는 동안 결과와 안내선이 보임, Shift: 45° 단위, 놓으면 실행취소 1단계). 선택 영역이 있으면 그 안(모양 그대로)만, 없으면 셀 전체에 칠하고, 불투명도가 낮은 쪽은 알파도 그대로 바뀝니다(아래가 그만큼 투명해짐).
  - **그라데이션 바**(왼쪽 0% ~ 오른쪽 100%, PowerPoint/Photoshop처럼): 띠 **위**에 **불투명도 정지점**(회색 상자 — 검정 = 투명, 흰색 = 불투명), 띠 **아래**에 **색 정지점**이 있습니다. 띠 위쪽 빈 곳을 누르면 불투명도 정지점, 띠나 아래쪽 빈 곳을 누르면 색 정지점이 그 위치에 생기고(값 = 그 지점의 지금 값), 상자를 누르면 고르며(파랗게 강조), 좌우로 끌면 위치가 바뀝니다. 고른 정지점의 **위치 %**와 — 색 정지점이면 **색**(칸을 누르면 색 고르기, HEX 입력, **기본색** 단추), 불투명도 정지점이면 **불투명도 %** — 를 고치고 **삭제**(또는 Delete)합니다. 처음·끝 정지점도 같고, 종류마다 2개 이상 남습니다. 최종 색 = 색 정지점 색(그 알파 포함) × 불투명도. 바에서 ←/→ = 같은 종류의 앞·뒤 정지점, ↑/↓ = 불투명도/색 줄로.
  - **보간**: 부드럽게(이웃한 정지점끼리 선형으로 섞음) / 단계(가장 가까운 정지점 값만 쓰는 띠). **디더링**: 없음 / 2×2 Bayer / 4×4 Bayer — 부드럽게일 때 이웃한 두 정지점의 색·불투명도를 순서 디더링 무늬로 섞습니다(픽셀 아트용 — 불투명도도 반투명 대신 무늬로 사라짐).
  - 색·불투명도 정지점과 보간·디더링은 다음 실행 때도 그대로입니다.
- **스포이드**: **기준: 현재 레이어 / 보이는 레이어 전체**(기본). Alt+클릭 임시 스포이드에도 적용됩니다.
- **밝게/어둡게**: 브러시, **세기** 1~50%(한 번에 바꾸는 명도, 기본 10%), 대칭.
- **디더링**: 브러시, **무늬** 체커(50%) / 성기게(25%) / 촘촘하게(75%) — 2×2 순서 디더링으로 기본색 비율을 정하고 나머지는 보조색, 대칭.
- **색 바꾸기 브러시**: 브러시, 대칭. **이동**: 순환. **피벗**: 위의 피벗 설정.
- **9-slice(S)**: Unity Sprite Border. 캔버스에 Unity 스프라이트 편집기처럼 **초록 선 4개**(0이면 가장자리)와 가운데 손잡이가 나오고, 선을 끌면 픽셀 경계에 맞춰 L·T·R·B가 바뀝니다(반대쪽 선은 넘지 않음, 놓을 때 실행취소 1단계). 도구 설정에는 L·T·R·B 숫자와 **모두 0**. 대상은 부위를 골랐으면 그 부위, 아니면 프레임 시트 모든 칸입니다. 그룹 화면에서는 보이는 부위마다 초록 선이 나와 바로 끌어 바꿀 수 있고(선이 아닌 곳을 끌면 부위 배치), 숫자는 부위를 골랐을 때 씁니다. 크기를 늘려도 선 바깥(모서리·가장자리)은 그대로, 가운데만 늘어납니다 — Unity에서 Image Type = Sliced로 쓰는 UI 버튼·패널용.
