# Gpixel

게임(특히 Unity 2D)용 픽셀 아트 편집기입니다. 프레임·레이어·태그(애니메이션)는 `.gpixel` 프로젝트에 저장되고, 저장할 때 **PNG 스프라이트 시트 + Unity `.meta`**가 함께 내보내집니다.

## 실행

- 필요: Windows, .NET 10 SDK
- `run.bat` 또는 `dotnet run --project src/Gpixel.App`
- 빌드·테스트: `dotnet build Gpixel.sln`, `dotnet test Gpixel.sln`
- 명령줄: `Gpixel.App.exe --open-folder <폴더> --open <파일.gpixel|파일.png>` (경로만 주면 `--open`)

## 화면 (Aseprite식 배치)

- **메뉴** 아래 **도구 옵션 막대**: 현재 도구에 맞는 옵션(브러시 크기, 픽셀 퍼펙트, 채움, 같은 색 전체, 오른쪽=지우개, 순환, 대칭)과 보기 옵션(격자, 타일 격자, 타일 모드, 피벗, 양파), 확대율.
- **왼쪽 끝 세로 도구 막대**(점 그림 아이콘, 도움말에 단축키) — 맨 위 폴더 단추로 파일 브라우저를 접고 펼침(F8).
- **파일 브라우저**: 폴더 트리, `.gpixel`·PNG 썸네일 목록(같은 이름이면 `.gpixel`만), 검색, 하위 폴더 포함, 파일 변경 감시, 우클릭(새 프로젝트·이름 바꾸기·탐색기에서 열기·휴지통으로 삭제). Unity Hub 프로젝트 목록에서 바로 열기.
- **팔레트 열**: 기본색/보조색, 팔레트 칸(기본 DB32), 팔레트 메뉴(추가·삭제·정렬·.hex/.gpl 불러오기·.hex 저장·이미지에서 만들기·비우기), 아래에 색 고르기(채도·명도 상자, 색상 막대, 알파 막대, RGBA·HSV·HEX, 최근 색 16개).
- **캔버스**: 현재 프레임 한 장(보이는 레이어 합성)을 보여 주고 현재 레이어의 셀에 그립니다. 1~64배 정수 확대, 체커 배경, 픽셀/타일 격자, 타일 모드(3×3 반복, 이어 그리기), 대칭 안내선, 피벗, 선택 영역, 양파 껍질, H를 누르는 동안 이전 프레임 보기.
- **타임라인(아래)**: 행 = 레이어(보이기·잠금·불투명도·이름), 열 = 프레임(번호·길이·실시간 썸네일), 위쪽 띠 = 태그(색, 방향, 반복). 재생, 프레임 추가/복제/삭제/끌어서 순서 변경, 레이어 추가/복제/삭제/순서/병합, Shift+클릭 범위로 태그 만들기.
- **미리보기(오른쪽 위)**: 현재 태그(없으면 모든 프레임)를 실시간 재생, 자체 FPS, 배율 1×/2×/4×/맞춤, 배경색.
- **Unity · 내보내기(오른쪽)**: 모드(Single/Multiple), PPU, Read/Write, 메시, 피벗(9방향·사용자 지정·프레임별), 9-slice 테두리, 저장 시 내보내기, 배치(가로 N칸/태그마다 한 줄), 간격, 테두리 잘라내기, 메타 쓰기(자동/항상/안 함), 폴더·이름, 만들어질 시트와 칸 이름 미리보기(읽기 전용).
- **상태 표시줄**: 커서 좌표 · 색 · 캔버스 크기 · 프레임/레이어 · 확대율 · 저장 상태.

## 파일

- `.gpixel`을 열고 저장합니다(Ctrl+S). 저장하면 설정대로 PNG 시트와 `.meta`(Unity 프로젝트 `Assets` 안이거나 이미 메타가 있으면)를 내보냅니다. 기존 메타의 guid·spriteID는 이름 기준으로 유지됩니다.
- 파일 브라우저에서 `.gpixel` 이름을 바꾸거나 휴지통으로 보낼 때, 저장 시 내보내기가 켜진 기본 경로의 PNG와 `.meta`·사이드카도 함께 이동하거나 휴지통으로 보냅니다(Unity guid 유지). 내보내기 폴더·이름을 따로 지정한 파일은 건드리지 않으며, 대상 이름에 파일이 있으면 덮어쓰지 않습니다.
- PNG를 열면 프로젝트로 가져옵니다(같은 이름 `.gpixel`이 있으면 그것을 엶). 메타/사이드카에 칸이 있으면 칸 크기가 서로 다를 때 **아틀라스**, 모두 같으면 "아틀라스로 / 애니메이션 프레임으로"를 묻습니다(애니메이션이면 칸마다 프레임 하나). 칸 정보가 없는 시트는 **프레임 > 격자로 나눠 프레임 만들기**로 칸 크기·칸 수·자동(덩어리)으로 나눌 수 있습니다.
- 저장할 때 `.gpixel`은 저장됐는데 PNG/메타 내보내기만 실패하면(다른 프로그램이 파일을 잡고 있는 등) 그렇게 알려 주고, 자기 저장을 "밖에서 바뀜"으로 묻지 않습니다.
- 내보낼 칸 이름: 타임라인 프레임 우클릭 > "내보낼 칸 이름…"(비우면 `{태그}_{번호}` / `{파일}_{번호}`).
- 설정은 `%AppData%\Gpixel\settings.json`(최근 폴더/파일, 창 배치, 확대율, 격자·타일 설정, 팔레트, 도구 옵션, 미리보기 설정).

## 아틀라스 모드

부위마다 크기·피벗이 다른 스프라이트 묶음(예: 캐릭터의 머리·몸·팔·다리)을 편집하고 한 장의 아틀라스 PNG + `.meta`로 내보냅니다.

- **만들기**: 새 프로젝트(Ctrl+N)에서 종류 "아틀라스"와 첫 스프라이트 크기를 고릅니다. 칸 크기가 서로 다른 PNG(메타/사이드카에 칸이 있는)를 열면 자동으로 아틀라스로 가져옵니다(이름·크기·피벗·테두리 그대로, 원래 위치 기억).
- **스프라이트 목록(아래)**: 타임라인 자리에 열 = 스프라이트(머리글에 이름·번호·크기, 9-slice가 있으면 ▦), 행 = 레이어(레이어 목록은 공통, 보이기·잠금·불투명도·추가·복제·병합 그대로). 머리글 클릭으로 고르기, 끌어서 순서 바꾸기, 더블클릭/F2로 이름 바로 고치기, 우클릭 메뉴. 단추: ＋스프라이트(이름·크기 입력, Alt+N), 복제(Alt+D), 삭제, 이름, 크기…(기준점 9방향, 피벗은 같은 그림 지점 유지), ⇠/⇢. 메뉴 **스프라이트(P)**에도 같은 명령이 있습니다. `,` `.` Home End는 스프라이트 사이를 움직입니다.
- **캔버스**: 고른 스프라이트 하나만 자기 크기로(보이는 레이어 합성) 보여 주고 현재 레이어 셀에 그립니다. 피벗 표시와 피벗 도구(K) 끌기, 9-slice 테두리 안내선(초록 점선). 캔버스 크기(Ctrl+Alt+C)는 현재 스프라이트 크기 바꾸기입니다.
- **오른쪽 독**: 피벗(9방향 프리셋·X/Y 숫자)과 9-slice 테두리(L/T/R/B)가 고른 스프라이트 대상이 됩니다. 내보내기에는 아틀라스 배치 옵션(최대 가로 0=자동, 간격, 2의 거듭제곱, 순서: 목록 순서/큰 것부터, 원래 위치 유지)과 이름이 표시된 배치 결과 미리보기·칸 목록(시트 위치)이 나옵니다. 모드는 항상 Multiple.
- **미리보기**: 고른 스프라이트를 보여 줍니다(재생 없음).
- **애니메이션 전용 기능은 꺼짐**: 태그, 재생, 양파 껍질, H(이전 프레임 보기), 프레임 추가/복제/삭제, 격자로 나눠 프레임 만들기, 캔버스 전체 뒤집기·회전. 움직임 테스트(F5)는 메뉴에 "아틀라스 프로젝트는 쓸 수 없음(미리보기만)"으로 표시되고 누르면 이유를 알려 줍니다.
- **저장**: `.gpixel`(스프라이트·셀) + 아틀라스 PNG + 사이드카 + `.meta`. "원래 위치 유지"가 켜져 있으면 가져온 칸 안에 아직 들어가는 스프라이트는 원래 rect 그대로, 새로 생겼거나 커진 것만 빈 곳에 배치되고, guid·spriteID·internalID는 이름 기준으로 유지됩니다.

## 도구

연필(B) · 지우개(E) · 채우기(G) · 스포이드(I, Alt/Ctrl+클릭) · 선(L) · 사각형(R) · 원(O) · 사각 선택(M) · 이동(V, 선택이 없으면 셀 전체를 밀고 "순환" 옵션) · 밝게/어둡게(D) · 디더링(T) · 색 바꾸기 브러시(C) · 피벗(K).
왼쪽 버튼 = 기본색, 오른쪽 = 보조색(옵션: 지우개). Shift+클릭 = 마지막 점에서 직선, Shift로 45°·정사각형·정원. 편집 메뉴에 외곽선 추가, 색 바꾸기, 뒤집기·회전, 캔버스 크기.
