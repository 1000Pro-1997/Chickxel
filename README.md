# Gpixel

게임(특히 Unity 2D)용 픽셀 아트 편집기입니다. 프레임·레이어·태그(애니메이션)는 `.gpixel` 프로젝트에 저장되고, 저장할 때 **PNG 스프라이트 시트 + Unity `.meta`**가 함께 내보내집니다.

## 설치·실행 (그냥 쓰기 — .NET 설치 필요 없음)

[Releases](https://github.com/1000Pro-1997/GPixel/releases)에서 zip을 받아 압축을 풉니다.

| OS | 파일 | 실행 |
|---|---|---|
| Windows 10/11 | `Gpixel-windows-x64.zip` | `Gpixel.exe` 더블클릭 |
| macOS 12+ (M1 이후 Apple Silicon) | `Gpixel-macos-arm64.zip` | `Gpixel.app`을 응용 프로그램 폴더로 옮긴 뒤 더블클릭 |
| macOS 12+ (Intel) | `Gpixel-macos-x64.zip` | 위와 같음 |

- 개발자 서명이 없는 앱이라 처음 한 번은 경고가 뜹니다.
  - Windows "PC 보호" 창: **추가 정보 → 실행**.
  - macOS "확인되지 않은 개발자": `Gpixel.app` **우클릭 → 열기**. 안 되면 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**, 또는 터미널에서 `xattr -dr com.apple.quarantine /Applications/Gpixel.app`.
- macOS: 단축키의 Ctrl은 ⌘(Command)입니다(예: ⌘S 저장, ⌘⇧O 폴더 열기). 메뉴와 도움말에도 ⌘로 표시됩니다. 스포이드는 ⌘/⌥+클릭.
- 명령줄: Windows `Gpixel.exe --open-folder <폴더> --open <파일.gpixel|파일.png>`, macOS `open -a Gpixel --args --open <파일>` (경로만 주면 `--open`).

## 배포 파일 만들기

- macOS: `./publish.sh 1.0.0` → `dist/`에 Windows zip + macOS(arm64·x64) zip 세 개(Mac 한 대에서 둘 다 만듦).
- Windows: `publish.bat 1.0.0` → `dist\Gpixel-windows-x64.zip`(Windows용만).
- GitHub: `git tag v1.0.0 && git push origin v1.0.0` 하면 Actions(`.github/workflows/release.yml`)가 테스트 후 세 zip을 만들어 릴리스에 올립니다.
- 결과물은 .NET 런타임을 품은 자체 포함 앱이라 받는 사람이 아무것도 설치하지 않아도 됩니다(zip 40MB 안팎).

## 개발

- 필요: .NET 10 SDK. UI는 Avalonia(Windows·macOS·Linux 공용 코드).
- 소스에서 바로 실행: Windows `run.bat` · macOS/Linux `./run.sh` (인수는 그대로 앱에 넘어감)
- 빌드·테스트: `dotnet build Gpixel.sln`, `dotnet test Gpixel.sln`
- 아이콘: 도구 아이콘은 `src/Gpixel.App/Assets/Tools/*.png`(16×16 단색 점 그림, 도구 막대에는 2배로 표시), 앱 아이콘은 `Assets/AppIcon/`(16×16 원본 `gpixel.png`에서 만든 `gpixel.ico`·`Gpixel.icns`·창/Dock 아이콘 `gpixel-256.png`). PNG는 Gpixel로 열어 바로 고칠 수 있습니다.

## 화면 (Aseprite식 배치)

- **메뉴** 아래 막대: 현재 도구 이름과 사용법 한 줄, 오른쪽에 보기 옵션(격자, 타일 격자, 타일 모드, 피벗, 양파)·확대율(누르면 100%~6400% 배율과 화면에 맞추기 목록)·**맞추기** 토글(켜면 이미지를 열 때마다 화면에 맞춤, 켜는 순간에도 한 번 맞춤; Ctrl+0은 언제든 지금 맞추기)·Claude 단추. 도구의 세부 설정은 오른쪽 독 **도구 설정**에 있습니다.
- **왼쪽 끝 세로 도구 막대**(점 그림 아이콘, 도움말에 단축키) — 맨 위 폴더 단추로 파일 브라우저를 접고 펼침(F8).
- **파일 브라우저**: F8·폴더 단추로 열고 닫을 때 폭이 부드럽게 늘고 줄며, 제목 줄 오른쪽 끝 새로 고침 아이콘(누르면 한 바퀴 돌며 새로 고침; 폴더·Unity 프로젝트 열기는 파일 메뉴 Ctrl+Shift+O / Ctrl+Shift+U), 폴더 트리, `.gpixel`·PNG 썸네일 목록(`.gpixel` 프로젝트는 썸네일 오른쪽 아래 파란 레이어 배지로 표시, 프로젝트가 내보내는 이미지 — 같은 이름 PNG와 등록된 프레임 시트·부위 아틀라스 — 는 목록에서 빼고 `.gpixel` 하나로 보여 주며, 마우스를 올리면 내보내는 파일 이름이 보이고 그 이름으로 검색해도 찾음), 검색, 하위 폴더 포함, 파일 변경 감시, 우클릭(새 프로젝트·이름 바꾸기·탐색기/Finder에서 보기·휴지통으로 삭제). Unity Hub 프로젝트 목록(Windows `%APPDATA%\UnityHub`, macOS `~/Library/Application Support/UnityHub`; 최신 Hub의 `hub.db`를 먼저, 없으면 `projects-v1.json`)에서 바로 열기.
- **팔레트 열**: 기본색/보조색(보조색 기본값 = 투명), 팔레트 칸(맨 앞은 늘 투명 칸; 기본색과 같은 칸은 흰 테두리, 보조색과 같은 칸은 파란 테두리, 둘이 같으면 반반 테두리 — 같은 색이 없으면 표시 없음, 기본 DB32), 팔레트 메뉴(추가·삭제·정렬·.hex/.gpl 불러오기·.hex 저장·이미지에서 만들기·비우기), 아래에 색 고르기(채도·명도 상자, 색상 막대, 알파 막대, RGBA·HSV·HEX, 최근 색 16개).
  - **팔레트 웹(Lospec)…**: [lospec.com 팔레트 목록](https://lospec.com/palette-list)을 앱 안에서 둘러봅니다(인터넷 필요). 정렬(인기·다운로드순·최신·이름순), 색 수(전체/최대/최소/정확히 N), 태그(예: `gameboy`, `pico8`, Enter로 검색)로 거르고, 태그 칸에 팔레트 이름(예: `sweetie 16`)을 넣으면 그 팔레트를 맨 위(★)에 보여 줍니다. 목록 끝까지 내리거나 **더 보기**로 다음 쪽을 불러옵니다. 고른 팔레트는 **팔레트로 쓰기**(지금 팔레트를 바꿈, 목록 더블클릭과 같음)·**현재 팔레트에 추가**(겹치는 색 제외)·**.hex로 저장**·**Lospec에서 보기**. 팔레트 저작권은 각 작성자에게 있습니다.
- **숫자 칸(공통)**: 위/아래 단추 없이 **좌우로 끌면** 값이 바뀝니다(3px마다 한 칸, Shift = 10배 느리게, Ctrl/⌘ = 10칸씩). 끌다가 화면 끝에 닿으면 커서가 반대편 끝으로 넘어가 계속 끌 수 있고, 끌지 않고 클릭하면 글자로 입력합니다. 프로젝트 설정을 끌어 바꾸면 실행취소 한 단계로 묶입니다.
- **캔버스**: 현재 프레임 한 장(보이는 레이어 합성)을 보여 주고 현재 레이어의 셀에 그립니다. 부위 레이어를 고르면 그 부위만 자기 크기로 보이고(주변 프레임은 흐리게), 그룹 레이어를 고르면 부위를 끌어 배치합니다. 1~64배 정수 확대, 체커 배경, 픽셀/타일 격자, 타일 모드(5×5 반복 — 한 변이 128px 넘는 큰 그림은 3×3, 이어 그리기), 대칭 안내선, 피벗, 선택 영역, 양파 껍질, H를 누르는 동안 이전 프레임 보기.
- **타임라인(아래)**: 행 = 레이어(눈·자물쇠 아이콘, 불투명도, 이름, 그룹은 ▾/▸로 접고 펼치며 부위는 그 아래 들여쓰기), 열 = 프레임(번호·길이·실시간 썸네일), 위쪽 띠 = 태그(색 괄호로 프레임을 묶어 보임). 도구 단추 없이 **우클릭 메뉴**로 다룹니다(프레임 머리글·셀: 태그 만들기, 빈 프레임·복제·삭제·옮기기·길이, 셀/프레임 복사·잘라내기·붙여넣기, 이전 프레임 그림 복사·셀 지우기, 피벗·칸 이름 / 레이어 이름: 이름·불투명도·보이기·잠금·부위 크기·위치·새 레이어·그룹·부위·복제·순서·병합·삭제 / 빈 곳: 새로 만들기). 재생은 미리보기에서 합니다.
  - **다음 프레임 칸**(마지막 프레임 뒤): 왼쪽 ⧉ = 마지막 프레임을 복사해 추가, 오른쪽 ＋ = 빈 프레임 추가(누른 행의 레이어가 골라짐).
  - **셀 고르기**: 셀을 누른 채 가로·세로로 끌면 사각형으로 여러 칸이 골라집니다. 처음 누른 칸은 파란 테두리, 끌어서 넓힌 칸은 옅은 칸으로 보입니다(Shift+클릭으로 넓히기도 됨). 프레임 번호를 끌면 프레임 전체(모든 레이어)가 골라집니다.
  - **태그**: 고른 범위에서 우클릭 **태그 만들기**로 묶습니다. 태그 상자 안쪽 양 끝(손잡이)에 마우스를 대면 ↔ 모양이 되고 끌어서 범위를 바꿉니다(태그가 겹쳐 있어도 각 상자 안쪽 끝을 잡으면 그 태그만 바뀜, 실행취소 1단계). 태그를 고르고 미리보기에서 재생하면 그 태그 안에서 반복합니다(재생 중에 태그를 바꿔도 바로 반영).
  - **셀 묶음 옮기기·복사**: 여러 칸을 골라 둔 뒤 그 안을 다시 눌러 끌면 묶음째 옮기고(끌지 않고 놓으면 그 칸 하나만 골라짐, 한 칸에서 끌면 범위 고르기), ⌥/Alt(또는 Ctrl/⌘)를 누른 채 놓으면 복사합니다. 놓을 자리가 파란 칸으로 미리 보이고, 마지막 프레임을 넘기면 프레임이 늘어납니다. 셀 크기·종류가 다른 행(예: 머리 칸을 몸 행에)으로는 옮기지 않고 알려 줍니다(그림이 사라지지 않게). 그룹 행 칸은 그 부위들째 옮깁니다(부위 수·크기가 같은 그룹으로만). 고른 프레임 번호를 다시 눌러 끌면 프레임 순서가 바뀝니다.
  - **복사·붙여넣기**: 칸을 골라 Ctrl/⌘+C(또는 X), 붙일 칸을 클릭하고 Ctrl/⌘+V — 클릭한 칸을 왼쪽 위로 같은 모양(행 × 프레임)으로 덮어씁니다. 프레임 번호로 골랐으면 프레임 전체를 복사하고 붙이면 뒤에 끼워 넣습니다(타임라인에 복사해 둔 것이 없으면 보통 그림 붙여넣기). 앞 프레임 그림을 그대로 가져오려면 셀 우클릭 "이전 프레임 그림 복사". Delete(⌫)는 고른 프레임(범위) 삭제, 셀 그림만 지우려면 우클릭 "셀 지우기". 프레임 번호 더블클릭 = 프레임 길이.
- **미리보기(오른쪽 위)**: 현재 태그(없으면 모든 프레임)를 실시간 재생, 자체 FPS, 배율 단추 하나(클릭하면 맞춤 → 1× → 2× → 4× 차례로, 오른쪽 클릭은 거꾸로), 배경(배율 단추 옆, 닫힌 상자는 색 견본만 / 펼치면 견본 + 이름: 체커·검정·흰색·회색·초록·사용자 색).
- **내보내기 창(Ctrl+E, 파일 > 내보내기…)**: 바꾸는 즉시 적용됩니다(설정 하나마다 실행취소 1단계). 아래 **닫기** 옆 파란 **내보내기**를 누르면 창을 닫고 지금 설정대로 내보냅니다(저장할 때 내보내기가 켜져 있으면 Ctrl+S만으로도 내보냄). 탭 순서는 내보내기 → Import Settings → 미리보기입니다.
  - **내보내기** 탭(처음 열리는 탭): 저장할 때 이미지 내보내기, 파일 형식(PNG 무손실·투명 / JPG 투명 없음, 품질 1~100 / TGA / BMP — 프레임 시트·부위 아틀라스 공통, 경로에 실제 확장자), **Unity .meta 같이 쓰기**(켜면 "언제": 자동(Unity Assets 안이거나 이미 .meta가 있을 때) / 항상, 끄면 이미지만), 칸 간격, 폴더; 프레임 시트(켜기, 배치 가로 N칸/태그마다 한 줄, 열 수, 테두리 잘라내기, Single 프레임, 이름)와 부위 아틀라스(부위가 있을 때: 켜기, 최대 가로, 순서, 2의 거듭제곱, 원래 위치 유지, 이름), 각각 내보낼 경로와 `.meta` 여부.
  - **Import Settings** 탭(`.meta`를 쓸 때만 보임): Unity Texture Importer 인스펙터와 같은 이름·값으로 `.meta`에 씁니다(프레임 시트·부위 아틀라스 공통, 부위 아틀라스는 항상 Multiple). Texture Type `Sprite (2D and UI)`·Texture Shape `2D`(고정), Sprite Mode(Single/Multiple), Pixels Per Unit, Mesh Type(Full Rect/Tight), Extrude Edges(0~32, Tight일 때), Pivot(Single일 때: Center·Top Left…·Custom, 피벗 도구(K)의 기본 피벗과 같은 값), Generate Physics Shape; Advanced: sRGB (Color Texture), Alpha Source(None/Input Texture Alpha/From Gray Scale), Alpha Is Transparency, Read/Write, Generate Mip Maps; Wrap Mode(Repeat/Clamp/Mirror/Mirror Once), Filter Mode(Point (no filter)/Bilinear/Trilinear), Aniso Level(0~16); Default 플랫폼: Max Size(Auto (fit) = 이미지가 들어가는 가장 작은 2의 거듭제곱, 32~16384), Resize Algorithm(Mitchell/Bilinear), Format(Automatic/RGBA 32 bit/RGB 24 bit), Compression(None/Low/Normal/High Quality), Use Crunch Compression, Compressor Quality(0~100). 기본값은 픽셀 아트용(Point, 압축 없음, 밉맵 끔, Clamp).
  - **미리보기** 탭: 만들어질 프레임 시트·부위 아틀라스와 칸 목록(읽기 전용, 칸을 고르면 그 프레임·부위로 이동).
- **도구 설정(오른쪽, 미리보기 아래)**: 제목 줄에 고른 도구 이름(예: `도구 설정 · 연필`)이 보이고, 그 도구의 세부 설정만 나옵니다(길면 스크롤). 도구 설정은 실행취소 대상이 아니며 다음 실행 때도 그대로입니다. 도구별 내용은 아래 [도구](#도구)에 있습니다. 설정이 없는 도구(사각 선택)는 한 줄 안내만 보입니다.
  - **피벗**(피벗 도구 K일 때): 그리는 대상(부위를 고르면 그 부위, 아니면 프레임·프레임별)의 피벗을 **픽셀 단위**로 보여 줍니다: X는 왼쪽에서, Y는 아래에서(Unity와 같음) 0.5px 단위, 옆에 최대값(`/ 16 px`). 9방향 단추는 정수 픽셀에 맞춥니다(가운데는 내림: 15px → 7px, 오른쪽 = 너비, 위 = 높이). "현재 프레임만 따로"로 프레임별 피벗. 피벗 도구로 끄는 동안에도 숫자가 따라갑니다(값 바꾸기는 실행취소 1단계).
- **상태 표시줄**: 커서 좌표 · 색 · 캔버스(부위면 부위) 크기 · 프레임/레이어(이름, 부위 크기) · 확대율 · 저장 상태.

## 파일

- `.gpixel`을 열고 저장합니다(Ctrl+S). 저장하면 설정대로 이미지와 `.meta`(Unity 프로젝트 `Assets` 안이거나 이미 메타가 있으면)를 내보냅니다. 기존 메타의 guid·spriteID는 이름 기준으로 유지됩니다.
- **파일 역할**: `.gpixel` = 편집 원본(레이어·프레임·태그·부위·내보내기 설정 — 편집 정보는 여기에만 저장), 내보낸 이미지 = 결과물(Unity·다른 프로그램용), `.meta` = Unity 설정. 예전 버전이 이미지 옆에 쓰던 `.png.gpixel.json`은 더 이상 만들지 않고, 다시 내보낼 때 지웁니다(남아 있는 것은 PNG를 가져올 때 애니메이션을 살리는 데만 읽음).
- 파일 브라우저에서 `.gpixel` 이름을 바꾸거나 휴지통으로 보낼 때, 저장 시 내보내기가 켜진 기본 경로의 PNG와 `.meta`(예전 `.png.gpixel.json`이 남아 있으면 그것도)를 함께 이동하거나 휴지통으로 보냅니다(Unity guid 유지). 내보내기 폴더·이름을 따로 지정한 파일은 건드리지 않으며, 대상 이름에 파일이 있으면 덮어쓰지 않습니다.
- PNG를 열면 프로젝트로 가져옵니다(같은 이름 `.gpixel`이 있거나 같은 폴더의 `.gpixel`이 그 PNG를 내보내기로 등록했으면 그 프로젝트를 엶). 메타/사이드카에 칸이 있으면 칸 크기가 서로 다를 때 **부위**(그룹 하나 + 칸마다 부위 하나), 모두 같으면 "부위로 / 애니메이션 프레임으로"를 묻습니다(애니메이션이면 칸마다 프레임 하나). 칸 정보가 없는 시트는 **프레임·레이어 > 격자로 나눠 프레임 만들기**로 칸 크기·칸 수·자동(덩어리)으로 나눌 수 있습니다.
- 저장할 때 `.gpixel`은 저장됐는데 PNG/메타 내보내기만 실패하면(다른 프로그램이 파일을 잡고 있는 등) 그렇게 알려 주고, 자기 저장을 "밖에서 바뀜"으로 묻지 않습니다.
- 내보낼 칸 이름: 타임라인 프레임 우클릭 > "내보낼 칸 이름…"(비우면 `{태그}_{번호}` / `{파일}_{번호}`).
- 설정은 Windows `%AppData%\Gpixel\settings.json`, macOS `~/Library/Application Support/Gpixel/settings.json`, Linux `~/.config/Gpixel/settings.json`(최근 폴더/파일, 창 배치, 확대율, 격자·타일 설정, 팔레트, 도구 옵션, 미리보기 설정).

## 부위(그룹) 레이어

캐릭터의 머리·몸·팔·다리처럼 크기가 서로 다른 부위를 프레임마다 그리고, 한 프레임 안에 배치해 애니메이션으로 쓰면서 부위별 스프라이트로도 내보냅니다. 타임라인의 가로축은 항상 프레임입니다.

- **그룹과 부위**: 그룹 레이어("합친 레이어") 아래에 부위 레이어가 들어갑니다. 부위마다 **자기 캔버스 크기**(예: Head 8×5)와 **프레임마다 자기 그림**이 있고, 프레임 캔버스 안의 **위치(오프셋)는 모든 프레임에 공통**입니다.
- **만들기**: 새 프로젝트(Ctrl+N)에서 "부위로 시작(그룹 + 첫 부위)"을 고르면 첫 부위 이름·크기를 정해 시작합니다. 나중에는 **프레임·레이어 > 새 그룹**(Ctrl+Shift+N), **새 부위…**(Shift+P — 현재 그룹에 추가, 그룹이 없으면 먼저 만듦), 타임라인 레이어 이름 우클릭 "새 그룹·새 부위…"나 그룹 우클릭 "부위 추가…"로 만듭니다.
- **타임라인**: 그룹 행은 ▾/▸로 접고 펼치며(파일에 저장, 실행취소 대상 아님) 칸에 그룹 합성 썸네일이 보입니다. 부위 행은 들여쓰기되어 이름과 크기(8×5)를 보여 줍니다. 그룹을 숨기거나 잠그면 부위도 함께 숨김·잠금. 부위는 자기 그룹 안에서만 순서를 바꾸고, 그룹은 부위와 함께 통째로 움직입니다. 병합은 일반 레이어끼리만 됩니다. 접고 펼치기와 행(레이어)·열(프레임) 추가·삭제(실행취소·다시 실행 포함)는 부드럽게 자라고 줄어드는 애니메이션으로 보입니다(다른 파일을 열 때는 바로).
- **배치(그룹 선택)**: 그룹을 고르면 캔버스에 프레임 합성이 보이고, 어떤 도구든 부위 위에 올리면 점선 테두리와 이름이 표시됩니다. 부위마다의 피벗(부위 아틀라스용)은 파란 점 표시로 보입니다(프레임 피벗은 주황, 피벗 표시를 끄면 함께 숨김). 끌어서 옮기고 놓으면 위치가 정해집니다(실행취소 1단계, 모든 프레임에 적용). 부위를 클릭하면 **고른 부위**(파란 실선 + 이름·위치)가 되고 빈 곳 클릭이나 Esc로 풀립니다. 화살표/Shift+화살표는 고른 부위를 1/8px 옮깁니다(고른 부위가 없으면 안내만). 부위를 더블클릭하면 그 부위 레이어를 고릅니다.
- **그리기(부위 선택)**: 부위를 고르면 그 부위만 자기 크기로 보이고 나머지 프레임은 흐리게 둘레에 보입니다. 좌표는 부위 안 기준입니다. 부위 크기는 **프레임·레이어 > 부위 크기…** 또는 부위 우클릭 "크기…"(기준점 9방향, 그린 픽셀은 캔버스 위 같은 자리에 남음), 위치는 우클릭 "위치…"로 숫자를 넣어 바꿉니다. 피벗 도구(K)와 9-slice 도구(S)는 고른 부위 대상입니다.
- **내보내기(둘 다, 각각 켜고 끔)**: 저장하면 ① **프레임 시트**(지금까지처럼 프레임마다 합성한 애니메이션 시트)와 ② **부위 아틀라스**(부위 × 프레임마다 칸 하나, 칸 이름은 프레임 0 = 부위 이름, 그다음 프레임 = `{부위}_{프레임}`이라 프레임을 늘려도 Unity에서 쓰던 스프라이트가 그대로; 자동 배치: 최대 가로 0=자동, 간격, 2의 거듭제곱, 순서, 원래 위치 유지; 항상 Multiple)를 각각 이미지 + `.meta`로 내보냅니다. 부위 아틀라스 이름을 비우면 `<프레임 시트 이름>_parts`. guid·spriteID·internalID는 이름 기준으로 유지됩니다.
- **예전 아틀라스 파일**: 예전 버전에서 만든 아틀라스 `.gpixel`을 열면 그룹 "부위" + 스프라이트마다 부위 하나로 바뀝니다(크기·피벗·9-slice·원래 위치 그대로). 부위 아틀라스 이름이 예전 아틀라스 PNG 이름으로 정해지므로 다시 저장해도 Unity의 guid·spriteID가 그대로 이어집니다(프레임 시트는 새 이름으로 따로 나옴). 여러 레이어였던 스프라이트는 한 장으로 합쳐지고 열 때 알려 줍니다.
- **PNG 가져오기**: 칸 크기가 서로 다른 시트(메타/사이드카에 칸이 있는)는 그룹 하나(파일 이름) + 칸마다 부위 하나로 가져옵니다. 부위 위치 = 원래 칸 위치, 캔버스 = 시트 크기. 부위 아틀라스 이름이 원래 PNG 이름이라 기존 `.meta`의 guid를 그대로 씁니다. 같은 그림의 사본이 생기지 않도록 프레임 시트는 꺼진 채로 가져옵니다(켜면 `<이름>_frames`).

## Claude 채팅 (말로 그리기·고치기)

VS Code의 Claude처럼 편집기 안에서 Claude와 대화하며 그림을 만들고 고칩니다. API 키를 넣지 않고, 컴퓨터에 설치된 **Claude Code**와 그 로그인(Claude 구독)을 그대로 씁니다.

- **열기**: 메뉴 아래 막대 오른쪽 **✦ Claude** 단추, 메뉴 **AI > Claude 채팅**, 또는 Ctrl+L. 작은 창으로 따로 뜨고 위치·크기를 기억합니다(앱을 닫을 때 열려 있었으면 다음에 다시 엶).
- **처음 한 번**: Claude Code가 없으면 설치 명령을 보여 줍니다(macOS/Linux `curl -fsSL https://claude.ai/install.sh | bash`, Windows PowerShell `irm https://claude.ai/install.ps1 | iex`, 복사 단추·직접 경로 지정). 로그인이 안 되어 있으면 **Claude로 로그인**(브라우저가 열림) 또는 **터미널에서 로그인**을 누르고, 끝나면 자동으로 채팅으로 넘어갑니다. 위쪽에 계정·요금제가 보입니다.
- **대화**: Enter 보내기, Shift+Enter 줄바꿈. **이미지…**로 참고 그림을 붙이고 **캔버스 첨부**로 지금 프레임을 보여 줄 수 있습니다. 모델(기본/sonnet/opus/haiku)과 **새 대화**는 위쪽에 있습니다. 답이 오는 동안 **정지**로 멈춥니다.
- **편집**: Claude는 편집기 안 MCP 서버(127.0.0.1, 이 앱이 띄운 Claude만 쓸 수 있는 토큰)의 도구로 열린 그림을 직접 고칩니다 — 문서 정보·그림 보기·픽셀 읽기, 점/줄 단위 그리기, 선·사각형·원, 채우기, 지우기, 색 바꾸기, 프레임·레이어·태그, 그룹·부위 만들기와 배치, 캔버스 크기, 팔레트·색, 새 프로젝트, 열기, 저장. 저장은 부탁할 때만 하고, 저장 안 된 수정이 있으면 새 프로젝트·열기를 하지 않고 물어봅니다.
- **되돌리기**: Claude의 답 한 번이 실행취소 **한 단계**입니다(Ctrl+Z로 통째로 되돌림). 답마다 결과 그림과 **이 단계 되돌리기 / 다시 적용** 단추가 붙습니다(뒤에 다른 편집이 있으면 함께 되돌릴지 묻습니다).
- 사용량은 Claude 구독에서 차감되며 답마다 비용·시간이 작게 표시됩니다. Claude Code를 실행 파일로 직접 부르는 방식이라, 이 기능을 넣은 앱을 **다른 사람에게 배포**할 때는 Anthropic의 이용 정책(제3자 앱에서 claude.ai 로그인 사용 제한)을 확인하세요.

## 도구

연필(B) · 지우개(E) · 채우기(G) · 스포이드(I, Alt/Ctrl+클릭 — 그리기 도구에서 Alt를 누르고 이미지 위에 있으면 커서가 스포이드로 바뀜) · 선(L) · 사각형(R) · 원(O) · 사각 선택(M) · 이동(V, 선택이 없으면 셀 전체를 밀고 "순환" 옵션) · 밝게/어둡게(D) · 디더링(T) · 색 바꾸기 브러시(C) · 피벗(K) · 9-slice(S).
왼쪽 버튼 = 기본색, 오른쪽 = 보조색(옵션: 지우개). 선·사각형·원이나 브러시 획을 그리는 중에 반대쪽 버튼을 누르면 그 획이 취소됩니다(기록 없음). Shift+클릭 = 마지막 점에서 직선, Shift로 45°·정사각형·정원. 편집 메뉴에 외곽선 추가, 색 바꾸기, 뒤집기·회전, 캔버스 크기.

도구를 고르면 오른쪽 독 **도구 설정**에 그 도구의 설정이 나옵니다.

- **브러시**(연필·지우개·밝게/어둡게·디더링·색 바꾸기 브러시): 모양 **사각 / 원 / 마름모**(원은 픽셀 아트 원: 3 = 십자, 4 = 12칸, 5 = 21칸, 7 = 37칸), 크기 1~32(숫자 칸을 좌우로 끌기, `[`/`]`), 옆에 실제 픽셀 모양 미리보기. 크기 1은 모양과 관계없이 한 점이고, 짝수 크기는 가운데에서 오른쪽·아래로 한 칸 더 넓습니다. 캔버스의 커서 테두리도 브러시 모양을 따라갑니다.
- **연필**: 브러시, 픽셀 퍼펙트(P, 크기 1일 때), 오른쪽 버튼 = 지우개, 대칭. **지우개**: 브러시, 픽셀 퍼펙트, 대칭.
- **선·사각형·원**: 선 두께·펜 모양(= 브러시 모양·크기, 사각형·원은 외곽선에만), 사각형·원은 **채움**(U), 오른쪽 버튼 = 지우개, 대칭.
- **채우기**: **허용 오차** 0~100%(0 = 지금처럼 정확히 같은 색만, 높일수록 비슷한 색도 같은 색으로 채움), **이어진 영역만**(끄면 맞는 색 전체, Shift+G), **대각선으로도 잇기**(8방향), **기준: 현재 레이어 / 보이는 레이어 전체**(보이는 레이어 전체면 합성된 모습으로 영역을 정하고 칠하기는 현재 레이어에), 오른쪽 버튼 = 지우개, 대칭.
  - 허용 오차는 클릭한 점의 색과 비교합니다: R·G·B·A 채널마다의 차이 중 가장 큰 값이 `허용 오차 % × 255` 이하이면 같은 색입니다. 완전 투명(알파 0) 픽셀은 RGB 없이 알파 차이만 잽니다.
- **스포이드**: **기준: 현재 레이어 / 보이는 레이어 전체**(기본). Alt/Ctrl+클릭 임시 스포이드에도 적용됩니다.
- **밝게/어둡게**: 브러시, **세기** 1~50%(한 번에 바꾸는 명도, 기본 10%), 대칭.
- **디더링**: 브러시, **무늬** 체커(50%) / 성기게(25%) / 촘촘하게(75%) — 2×2 순서 디더링으로 기본색 비율을 정하고 나머지는 보조색, 대칭.
- **색 바꾸기 브러시**: 브러시, 대칭. **이동**: 순환. **피벗**: 위의 피벗 설정.
- **9-slice(S)**: Unity Sprite Border. 캔버스에 Unity 스프라이트 편집기처럼 **초록 선 4개**(0이면 가장자리)와 가운데 손잡이가 나오고, 선을 끌면 픽셀 경계에 맞춰 L·T·R·B가 바뀝니다(반대쪽 선은 넘지 않음, 놓을 때 실행취소 1단계). 도구 설정에는 L·T·R·B 숫자와 **모두 0**. 대상은 부위를 골랐으면 그 부위, 아니면 프레임 시트 모든 칸입니다. 그룹 화면에서는 보이는 부위마다 초록 선이 나와 바로 끌어 바꿀 수 있고(선이 아닌 곳을 끌면 부위 배치), 숫자는 부위를 골랐을 때 씁니다. 크기를 늘려도 선 바깥(모서리·가장자리)은 그대로, 가운데만 늘어납니다 — Unity에서 Image Type = Sliced로 쓰는 UI 버튼·패널용.
